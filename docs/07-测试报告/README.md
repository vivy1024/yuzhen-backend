## 🚀 快速开始

### 运行测试

```bash
# 在Docker容器内运行所有测试
docker exec fitness_php_v2 php artisan test

# 运行特定测试
docker exec fitness_php_v2 php artisan test --filter=UserTest

# 生成测试覆盖率报告
docker exec fitness_php_v2 php artisan test --coverage
```

### 测试环境

- **PHP版本**: 8.2+
- **Laravel版本**: 10.x
- **测试框架**: PHPUnit
- **数据库**: MySQL 8.0（测试数据库）

## 📝 测试报告规范

### 报告格式

每个测试报告应包含：

1. **测试概述**：测试目的、范围、环境
2. **测试用例**：详细的测试用例列表
3. **测试结果**：通过/失败统计、详细结果
4. **问题记录**：发现的问题和解决方案
5. **性能指标**：响应时间、资源使用等
6. **结论建议**：测试结论和改进建议

### 命名规范

- 格式：`XX-测试类型-测试报告.md`
- 示例：`01-用户认证-单元测试报告.md`
