# 会员系统配置开关说明

**版本**: v1.0.0  
**更新日期**: 2026-01-09  
**状态**: ✅ 已完成

---

## 功能概述

会员系统配置开关允许通过环境变量一键控制会员系统的启用/禁用状态，满足个人开发者合规要求。

**核心原因**：
- 个人开发者没有企业资质
- 个人ICP备案不能涉及经营性业务（会员订阅属于经营性业务）
- 当前采用打赏模式替代会员系统
- 获得个人独资企业资质后可一键启用

---

## 配置方式

### 环境变量

```bash
# 禁用会员系统（默认）
MEMBERSHIP_SYSTEM_ENABLED=false

# 启用会员系统（获得企业资质后）
MEMBERSHIP_SYSTEM_ENABLED=true
```

### 配置文件位置

- 本地开发: `.env`
- 生产环境: `.env.production` 或 Zeabur 环境变量

## 统一用户限制

会员系统禁用时，所有用户使用以下统一限制：

| 功能 | 限制 |
|------|------|
| AI对话 | 每天10次 |
| 训练计划 | 最多5个 |
| DAG模板 | 全部13个开放 |
| 复杂度限制 | simple=10, medium=5, complex=3 |
| 解锁所有动作 | ✅ |
| AI推荐 | ✅ |
| 数据分析 | ❌ |
| 教练服务 | ❌ |

## 启用会员系统步骤

1. 获得个人独资企业资质
2. 完成企业ICP备案变更
3. 在 Zeabur 环境变量设置 `MEMBERSHIP_SYSTEM_ENABLED=true`
4. 重启服务
5. 更新官网会员体系描述
