# 用户自建训练/饮食计划 — 设计说明

**版本**: v1.0.0 | **日期**: 2026-02-22 | **Spec**: user-custom-plans

---

## 概述

支持用户手动创建训练计划（含周视图动作安排 + 饮食计划），以及从官方模板一键创建。

## 数据模型

### 核心表关系

```
training_plans (1)
  ├── training_plan_exercises (N) → exercises (动作库)
  └── user_nutrition_plans (N)    → foods (食物库)
```

### training_plan_exercises 新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| day_of_week | tinyint | 星期几（1=周一 ~ 7=周日），支持周视图排列 |

### user_nutrition_plans（新表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| plan_id | bigint | 关联 training_plans.id |
| food_id | bigint(nullable) | 关联 foods.id |
| food_name | varchar(100) | 食物名称（冗余，防止食物删除后丢失） |
| meal_type | enum | breakfast / lunch / dinner / snack |
| portion_grams | int | 份量（克） |
| day_of_week | tinyint(nullable) | 星期几 |
| notes | varchar(255, nullable) | 备注 |

### plan_templates（新表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| name | varchar(100) | 模板名称 |
| description | text(nullable) | 描述 |
| goal | varchar(30) | 训练目标 |
| level | varchar(20) | 难度等级 |
| duration_weeks | int | 周期（周） |
| workouts_per_week | int | 每周训练次数 |
| exercises_data | json | 预置动作配置 |
| is_official | boolean | 是否官方模板 |

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/training/plans | 列表（支持 type 筛选） |
| POST | /api/training/plans | 创建（含 exercises + nutrition 嵌套） |
| GET | /api/training/plans/:id | 详情（with planExercises.exercise + nutritionPlans.food） |
| PUT | /api/training/plans/:id | 更新（exercises + nutrition sync） |
| DELETE | /api/training/plans/:id | 软删除（级联） |
| POST | /api/training/plans/:id/copy | 复制（含动作+饮食） |
| GET | /api/training/templates | 模板列表（筛选 goal/level） |
| POST | /api/training/templates/:id/use | 从模板创建计划 |

## 关键设计决策

1. **复用 training_plans 表**：通过 `type=manual` 区分手动创建和 AI 生成，避免新建表
2. **food_name 冗余存储**：nutrition_plans 同时存 food_id 和 food_name，防止食物库变动影响已有计划
3. **周视图 day_of_week**：exercises 和 nutrition 都支持按星期分组，前端用 Tabs 切换
4. **模板 exercises_data 用 JSON**：模板的动作配置存为 JSON，使用时展开为独立记录
5. **营养数据前端缓存**：NutritionPlanTab 在选择食物时缓存 `_energy_per100` 等字段，避免重复请求
