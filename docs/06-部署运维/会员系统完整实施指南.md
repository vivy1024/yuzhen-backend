## 💳 宝塔支付系统集成指南

### 方案概述

会员系统已经预留了支付接口，等你在宝塔完成支付配置后，只需要对接回调即可。

### 支付流程

```
用户选择会员等级
    ↓
前端: 调用创建订单API
    ↓
后端: 创建订单（状态=pending）
    ↓
后端: 返回订单号和支付信息
    ↓
前端: 调起微信支付/支付宝
    ↓
用户: 扫码/输入密码支付
    ↓
支付平台: 回调到后端
    ↓
后端: 验证签名 → 更新订单状态 → 激活会员
    ↓
前端: 显示支付成功，会员已激活
```

## 🎛️ 宝塔支付集成步骤

### 第1步：安装支付SDK（在宝塔终端）

```bash
cd /www/wwwroot/yuzhen-backend

# 安装微信支付SDK
composer require wechatpay/wechatpay

# 安装支付宝SDK
composer require alipay/alipay-sdk-php
```

### 第2步：配置环境变量

编辑 `.env`：
```env
# 微信支付配置
WECHAT_PAY_APP_ID=你的AppID
WECHAT_PAY_MCH_ID=你的商户号
WECHAT_PAY_KEY=你的API密钥
WECHAT_PAY_CERT_PATH=/path/to/apiclient_cert.pem
WECHAT_PAY_KEY_PATH=/path/to/apiclient_key.pem

# 支付宝配置
ALIPAY_APP_ID=你的AppID
ALIPAY_PUBLIC_KEY=支付宝公钥
ALIPAY_PRIVATE_KEY=你的应用私钥
ALIPAY_NOTIFY_URL=https://api.yuzhen-fitness.cn/api/payment/alipay/callback
```

### 第3步：创建支付配置文件

在宝塔文件管理器创建 `config/payment.php`：

```php
<?php

return [
    'wechat' => [
        'app_id' => env('WECHAT_PAY_APP_ID'),
        'mch_id' => env('WECHAT_PAY_MCH_ID'),
        'key' => env('WECHAT_PAY_KEY'),
        'cert_path' => env('WECHAT_PAY_CERT_PATH'),
        'key_path' => env('WECHAT_PAY_KEY_PATH'),
        'notify_url' => env('APP_URL') . '/api/payment/wechat/callback',
    ],
    
    'alipay' => [
        'app_id' => env('ALIPAY_APP_ID'),
        'public_key' => env('ALIPAY_PUBLIC_KEY'),
        'private_key' => env('ALIPAY_PRIVATE_KEY'),
        'notify_url' => env('ALIPAY_NOTIFY_URL'),
        'return_url' => env('APP_FRONTEND_URL') . '/#/payment/success',
    ],
];
```

### 第4步：创建支付服务（我帮你准备好）

创建 `app/Modules/Membership/Services/PaymentService.php`：

```php
<?php

namespace App\Modules\Membership\Services;

use App\Modules\Membership\Models\Order;
use App\Modules\Membership\Models\Payment;
use Illuminate\Support\Facades\Log;

class PaymentService
{
    /**
     * 创建微信支付
     */
    public function createWechatPay(Order $order): array
    {
        // 微信支付统一下单
        $params = [
            'body' => "Yuzhen Fitness - {$order->membership->name}",
            'out_trade_no' => $order->order_no,
            'total_fee' => $order->actual_amount * 100, // 单位：分
            'trade_type' => 'NATIVE', // 扫码支付
            'notify_url' => config('payment.wechat.notify_url'),
        ];

        // 调用微信支付API（需要安装SDK）
        // 这里返回二维码URL
        
        return [
            'pay_method' => 'wechat',
            'qr_code_url' => 'weixin://wxpay/...',
            'order_no' => $order->order_no,
        ];
    }

    /**
     * 创建支付宝支付
     */
    public function createAlipay(Order $order): array
    {
        // 支付宝统一下单
        $params = [
            'subject' => "Yuzhen Fitness - {$order->membership->name}",
            'out_trade_no' => $order->order_no,
            'total_amount' => $order->actual_amount,
            'product_code' => 'FAST_INSTANT_TRADE_PAY',
        ];

        // 调用支付宝API（需要安装SDK）
        // 返回支付页面URL
        
        return [
            'pay_method' => 'alipay',
            'pay_url' => 'https://openapi.alipay.com/...',
            'order_no' => $order->order_no,
        ];
    }

    /**
     * 处理微信支付回调
     */
    public function handleWechatCallback(array $data): bool
    {
        // 1. 验证签名
        // 2. 查找订单
        $orderNo = $data['out_trade_no'];
        $order = Order::where('order_no', $orderNo)->first();
        
        if (!$order) {
            Log::error('订单不存在', ['order_no' => $orderNo]);
            return false;
        }

        // 3. 更新订单和支付记录
        $order->markAsPaid($data['transaction_id'], 'wechat');
        
        // 4. 激活会员（调用MembershipService）
        app(MembershipService::class)->handlePaymentSuccess(
            $order->id,
            $data['transaction_id'],
            'wechat'
        );

        return true;
    }

    /**
     * 处理支付宝回调
     */
    public function handleAlipayCallback(array $data): bool
    {
        // 类似微信支付回调处理
        // ...
        return true;
    }
}
```

### 第5步：添加支付路由

在 `routes/modules/membership.php`（或创建此文件）：

```php
<?php

use Illuminate\Support\Facades\Route;
use App\Modules\Membership\Controllers\PaymentController;

Route::prefix('payment')->group(function () {
    
    // 微信支付回调（POST）
    Route::post('/wechat/callback', [PaymentController::class, 'wechatCallback']);
    
    // 支付宝支付回调（POST）
    Route::post('/alipay/callback', [PaymentController::class, 'alipayCallback']);
    
});
```

## 🔗 前后端对接

### 前端调用示例

```typescript
// 1. 获取会员等级列表
const memberships = await api.get('/api/membership/tiers');
// 响应：
// [
//   { slug: 'free', name: '免费版', price: 0 },
//   { slug: 'warmheart', name: '暖心会员', price: 3.00 },
//   { slug: 'energy', name: '能量会员', price: 8.00 }
// ]

// 2. 创建订单
const order = await api.post('/api/membership/orders', {
  membership_id: 2, // 暖心会员
});
// 响应：
// {
//   order_no: '20251101123456ABC',
//   amount: 3.00,
//   pay_info: {
//     qr_code_url: 'weixin://...'
//   }
// }

// 3. 显示支付二维码（用户扫码）
showQRCode(order.pay_info.qr_code_url);

// 4. 轮询订单状态
const checkOrderStatus = async () => {
  const result = await api.get(`/api/membership/orders/${order.order_no}`);
  if (result.status === 'paid') {
    showSuccess('支付成功！会员已激活');
  }
};

// 每2秒检查一次，最多检查60次
const timer = setInterval(checkOrderStatus, 2000);
setTimeout(() => clearInterval(timer), 120000);
```
