# 🔐 微信开放平台配置指南

## 📋 前提条件

✅ 已申请微信开放平台账号（https://open.weixin.qq.com/）

---

## 🎯 配置步骤

### 第1步：创建网站应用

1. 登录微信开放平台：https://open.weixin.qq.com/
2. 进入 **管理中心** → **网站应用**
3. 点击 **创建网站应用**

### 第2步：填写应用信息

**基本信息**:
- **应用名称**: Yuzhen Fitness（或你的应用名称）
- **应用简介**: 健身训练APP
- **应用官网**: http://yourdomain.com
- **应用图标**: 上传120x120像素的图标

**接口信息**:
- **授权回调域**: 
  - 开发环境: `localhost:8000`
  - 生产环境: `yourdomain.com`

⚠️ **重要**: 回调域不要加 `http://` 或 `https://`，只填域名！

### 第3步：获取AppID和AppSecret

提交审核通过后，在应用详情页可以看到：
- **AppID**: `wx1234567890abcdef`（示例）
- **AppSecret**: 点击查看，需要管理员扫码确认

**复制这两个值，待会要用！**

## ⚙️ 后端配置

### 1. 编辑 `.env` 文件

```env
# 微信开放平台配置
WECHAT_APP_ID=wx1234567890abcdef
WECHAT_APP_SECRET=your_app_secret_here

# 回调地址（开发环境）
WECHAT_REDIRECT_URI=http://localhost:8000/api/social/callback/wechat

# 回调地址（生产环境）
# WECHAT_REDIRECT_URI=https://yourdomain.com/api/social/callback/wechat
```

## 🔄 完整登录流程

### 前端流程

```javascript
// 1. 用户点击"微信登录"按钮
function handleWechatLogin() {
  // 2. 调用后端获取授权URL
  const response = await api.get('/api/social/login/wechat');
  
  // 3. 跳转到微信授权页面
  window.location.href = response.data.authorization_url;
  
  // 4. 用户在微信页面授权后，会自动回调到：
  //    http://localhost:8000/api/social/callback/wechat?code=xxx&state=xxx
  
  // 5. 后端处理完成后重定向回前端（带token）
  //    http://localhost:9000/#/login/callback?token=xxx
}

// 6. 前端接收token并保存
function handleLoginCallback() {
  const urlParams = new URLSearchParams(window.location.hash.split('?')[1]);
  const token = urlParams.get('token');
  
  if (token) {
    localStorage.setItem('access_token', token);
    router.push('/dashboard');
  }
}
```

## 🧪 测试步骤

### 1. 本地测试

由于微信不支持 `localhost` 回调，需要使用内网穿透工具：

**推荐工具**:
- **ngrok**: https://ngrok.com/
- **frp**: https://github.com/fatedier/frp
- **花生壳**: https://hsk.oray.com/

**ngrok示例**:
```bash
# 安装ngrok
npm install -g ngrok

# 启动内网穿透
ngrok http 8000

# 会得到一个公网地址，例如：
# https://abc123.ngrok.io -> http://localhost:8000
```

**更新配置**:
```env
# 使用ngrok地址
WECHAT_REDIRECT_URI=https://abc123.ngrok.io/api/social/callback/wechat
```

### 2. 更新微信开放平台

回到微信开放平台，修改授权回调域为：
```
abc123.ngrok.io
```

### 3. 测试登录

```bash
# 访问测试URL
curl http://localhost:8000/api/social/login/wechat

# 或在浏览器中打开
http://localhost:8000/api/social/login/wechat
```

## 📱 微信扫码登录（可选）

如果要实现"扫码登录"，需要：

### 1. 前端显示二维码

```html
<!-- 微信登录二维码容器 -->
<div id="wechat-qrcode"></div>

<script src="https://res.wx.qq.com/connect/zh_CN/htmledition/js/wxLogin.js"></script>
<script>
  new WxLogin({
    self_redirect: false,
    id: "wechat-qrcode",
    appid: "wx1234567890abcdef",
    scope: "snsapi_login",
    redirect_uri: encodeURIComponent("http://localhost:8000/api/social/callback/wechat"),
    state: "STATE",
    style: "black", // 可选：black/white
    href: "" // 可选：自定义样式
  });
</script>
```

### 2. 用户扫码授权

用户用微信扫描二维码 → 授权 → 自动回调到后端

## 🔧 常见问题

### Q1: redirect_uri参数错误

**原因**: 回调地址与微信开放平台配置不一致

**解决**:
1. 检查 `.env` 中的 `WECHAT_REDIRECT_URI`
2. 检查微信开放平台的授权回调域
3. 确保两者完全一致（不包括http://前缀）

### Q2: 未获取到unionid

**原因**: 应用未绑定到微信开放平台

**解决**:
1. 进入微信开放平台
2. 绑定小程序/公众号到开放平台
3. 绑定后可获取统一的unionid

### Q3: scope参数错误

**解决**: 网站应用使用 `snsapi_login`，公众号使用 `snsapi_userinfo`
