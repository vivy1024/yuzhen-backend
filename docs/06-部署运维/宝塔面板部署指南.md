## 🚀 宝塔面板安装

### 第1步：连接服务器

**Windows用户** - 使用 PowerShell:
```powershell
ssh root@120.xx.xx.xx
# 输入密码
```

**或使用宝塔SSH工具**: https://www.bt.cn/bbs/thread-1143-1-1.html

### 第2步：安装宝塔面板

#### Ubuntu/Debian系统:
```bash
# 一键安装脚本
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec
```

#### CentOS系统:
```bash
# 一键安装脚本
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec
```

**安装时间**: 约5-10分钟

### 第3步：获取登录信息

安装完成后，会显示：
```
==================================================================
Congratulations! Installed successfully!
==================================================================
外网面板地址: https://120.xx.xx.xx:8888/xxxxxxxx
内网面板地址: https://10.0.0.1:8888/xxxxxxxx
username: xxxxxxxx
password: xxxxxxxx
If you cannot access the panel,
release the following panel port [8888] in the security group
==================================================================
```

⚠️ **请务必保存这些信息！**

### 第4步：访问宝塔面板

1. 浏览器打开：`https://120.xx.xx.xx:8888/xxxxxxxx`
2. 输入用户名和密码
3. 首次登录会要求绑定宝塔账号（可跳过）

## 🌐 域名与SSL配置

### 第1步：添加网站

#### 添加API后端站点

1. 点击 **网站** → **添加站点**
2. 配置：
   ```
   域名: api.yuzhen-fitness.cn
   根目录: /www/wwwroot/yuzhen-backend/public
   PHP版本: PHP-82
   数据库: MySQL 8.0（自动创建）
   ```
3. 点击**提交**

#### 添加前端站点

1. 再次点击 **添加站点**
2. 配置：
   ```
   域名: yuzhen-fitness.cn,www.yuzhen-fitness.cn
   根目录: /www/wwwroot/yuzhen-frontend
   PHP版本: 纯静态
   ```

### 第2步：配置DNS解析

在阿里云DNS控制台添加：

```
# API后端
类型: A
主机记录: api
记录值: 120.xx.xx.xx
TTL: 600

# 前端主站
类型: A
主机记录: @
记录值: 120.xx.xx.xx
TTL: 600

类型: A
主机记录: www
记录值: 120.xx.xx.xx
TTL: 600
```

### 第3步：申请SSL证书

**方式A: 使用Let's Encrypt免费证书（推荐）**

1. 点击网站 → **设置** → **SSL**
2. 选择 **Let's Encrypt**
3. 勾选你的域名
4. 点击 **申请**
5. 等待1-2分钟自动完成

**证书有效期**: 90天，宝塔会自动续期

**方式B: 使用阿里云SSL证书**

1. 在阿里云申请免费证书
2. 下载Nginx证书
3. 在宝塔 → **SSL** → **其他证书**
4. 粘贴证书内容
5. 保存

### 第4步：强制HTTPS

在 **SSL** 页面：
```
✅ 强制HTTPS
✅ HSTS
✅ HTTP/2
```

## 🔧 Laravel后端部署

### 第1步：上传代码

**方式A: 使用Git（推荐）**

在宝塔终端执行：
```bash
# 进入网站目录
cd /www/wwwroot/

# 克隆代码（如果有Git仓库）
git clone https://github.com/your-repo/yuzhen-backend.git

# 或者从本地上传（见方式B）
```

**方式B: 使用宝塔文件管理器**

1. 点击 **文件**
2. 进入 `/www/wwwroot/`
3. 点击 **上传** 或 **远程下载**
4. 上传整个 `yuzhen-backend` 文件夹

### 第2步：安装Composer依赖

在宝塔终端执行：
```bash
cd /www/wwwroot/yuzhen-backend

# 安装Composer（如果未安装）
php -r "copy('https://install.phpcomposer.com/installer', 'composer-setup.php');"
php composer-setup.php
php -r "unlink('composer-setup.php');"
mv composer.phar /usr/local/bin/composer

# 安装依赖
composer install --optimize-autoloader --no-dev
```

### 第3步：配置环境变量

1. 复制`.env.example`为`.env`:
```bash
cp .env.example .env
```

2. 编辑`.env`:
```bash
nano .env
# 或在宝塔文件管理器中直接编辑
```

**生产环境配置**:
```env
APP_NAME="Yuzhen Fitness"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://api.yuzhen-fitness.cn
APP_FRONTEND_URL=https://yuzhen-fitness.cn

# 数据库（宝塔自动创建的）
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=yuzhen_backend
DB_USERNAME=yuzhen_backend
DB_PASSWORD=宝塔生成的密码

# Redis
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

# 会话
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis

# 缓存
CACHE_DRIVER=redis

# 邮件（如需要）
MAIL_MAILER=smtp
MAIL_HOST=smtp.aliyun.com
MAIL_PORT=465
MAIL_USERNAME=noreply@yuzhen-fitness.cn
MAIL_PASSWORD=your_password
MAIL_ENCRYPTION=ssl
MAIL_FROM_ADDRESS=noreply@yuzhen-fitness.cn
MAIL_FROM_NAME="Yuzhen Fitness"
```

### 第4步：生成密钥

```bash
php artisan key:generate
php artisan jwt:secret
```

### 第5步：运行数据库迁移

```bash
php artisan migrate --force
php artisan db:seed --force
```

### 第6步：优化Laravel

```bash
# 缓存配置
php artisan config:cache

# 缓存路由
php artisan route:cache

# 缓存视图
php artisan view:cache

# 优化自动加载
composer dump-autoload --optimize
```

### 第7步：设置目录权限

在宝塔终端：
```bash
cd /www/wwwroot/yuzhen-backend

# 设置所有者
chown -R www:www /www/wwwroot/yuzhen-backend

# 设置权限
chmod -R 755 /www/wwwroot/yuzhen-backend
chmod -R 777 storage bootstrap/cache
```

### 第8步：配置Nginx（重要！）

在宝塔 → 网站 → **设置** → **配置文件**:

```nginx
server {
    listen 80;
    listen 443 ssl http2;
    server_name api.yuzhen-fitness.cn;
    
    # SSL证书（宝塔自动配置）
    ssl_certificate /www/server/panel/vhost/cert/api.yuzhen-fitness.cn/fullchain.pem;
    ssl_certificate_key /www/server/panel/vhost/cert/api.yuzhen-fitness.cn/privkey.pem;
    
    # Laravel根目录
    root /www/wwwroot/yuzhen-backend/public;
    index index.php index.html;
    
    # 访问日志
    access_log /www/wwwlogs/api.yuzhen-fitness.cn.log;
    error_log /www/wwwlogs/api.yuzhen-fitness.cn.error.log;
    
    # Laravel URL重写
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    
    # PHP处理
    location ~ \.php$ {
        fastcgi_pass unix:/tmp/php-cgi-82.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
    
    # 隐藏敏感文件
    location ~ /\.(env|git) {
        deny all;
    }
    
    # CORS配置
    add_header Access-Control-Allow-Origin https://yuzhen-fitness.cn always;
    add_header Access-Control-Allow-Methods "GET, POST, PUT, DELETE, OPTIONS" always;
    add_header Access-Control-Allow-Headers "Authorization, Content-Type, X-Requested-With" always;
    add_header Access-Control-Max-Age 86400 always;
    
    # OPTIONS预检请求
    if ($request_method = 'OPTIONS') {
        return 204;
    }
}
```

点击**保存** → **重载配置**

## 🌐 前端PWA部署

### 第1步：构建前端

在本地开发环境：
```bash
cd yuzhen_fitness_v2

# 修改API地址
# 编辑 src/boot/axios.js
# 改为：baseURL: 'https://api.yuzhen-fitness.cn'

# 构建生产版本
npm run build
# 或
yarn build
```

会生成 `dist/spa/` 目录

### 第2步：上传到服务器

使用宝塔文件管理器：
1. 进入 `/www/wwwroot/yuzhen-frontend/`
2. 上传 `dist/spa/` 中的所有文件

### 第3步：配置Nginx

在宝塔 → 网站 → **设置** → **配置文件**:

```nginx
server {
    listen 80;
    listen 443 ssl http2;
    server_name yuzhen-fitness.cn www.yuzhen-fitness.cn;
    
    # SSL证书
    ssl_certificate /www/server/panel/vhost/cert/yuzhen-fitness.cn/fullchain.pem;
    ssl_certificate_key /www/server/panel/vhost/cert/yuzhen-fitness.cn/privkey.pem;
    
    root /www/wwwroot/yuzhen-frontend;
    index index.html;
    
    # Gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;
    
    # PWA缓存策略
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # Service Worker不缓存
    location = /service-worker.js {
        add_header Cache-Control "no-cache, no-store, must-revalidate";
        expires 0;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

## ⏰ 定时任务

Laravel需要运行定时任务调度器。

### 添加Cron任务

1. 宝塔 → **计划任务**
2. 任务类型：**Shell脚本**
3. 任务名称：Laravel调度器
4. 执行周期：**每分钟**
5. 脚本内容：
```bash
#!/bin/bash
cd /www/wwwroot/yuzhen-backend && php artisan schedule:run >> /dev/null 2>&1
```

### 队列Worker（如果使用队列）

创建Supervisor配置：

1. 宝塔终端：
```bash
nano /etc/supervisor/conf.d/laravel-worker.conf
```

2. 添加配置：
```ini
[program:laravel-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /www/wwwroot/yuzhen-backend/artisan queue:work redis --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www
numprocs=2
redirect_stderr=true
stdout_logfile=/www/wwwroot/yuzhen-backend/storage/logs/worker.log
stopwaitsecs=3600
```

3. 启动：
```bash
supervisorctl reread
supervisorctl update
supervisorctl start laravel-worker:*
```

## 🆘 常见问题

### Q1: 502 Bad Gateway

**原因**: PHP进程未启动或配置错误

**解决**:
```bash
# 重启PHP
systemctl restart php-fpm-82

# 检查PHP进程
ps aux | grep php-fpm
```

### Q2: 403 Forbidden

**原因**: 目录权限问题

**解决**:
```bash
chown -R www:www /www/wwwroot/yuzhen-backend
chmod -R 755 /www/wwwroot/yuzhen-backend
chmod -R 777 storage bootstrap/cache
```

### Q3: 数据库连接失败

**检查**:
1. 数据库名、用户名、密码是否正确
2. MySQL服务是否启动
3. 3306端口是否开放

### Q4: SSL证书申请失败

**检查**:
1. DNS解析是否生效（ping domain.com）
2. 80端口是否开放
3. 域名是否已备案（国内服务器需要）
