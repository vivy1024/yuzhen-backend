## 🗄️ 数据库结构

### 1. memberships（会员等级表）

```sql
CREATE TABLE `memberships` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `name` varchar(50) NOT NULL COMMENT '等级名称',
  `slug` varchar(50) NOT NULL COMMENT '唯一标识',
  `tier` varchar(50) NOT NULL DEFAULT 'free' COMMENT '等级标识：free/warmheart/energy',
  `price` decimal(10,2) NOT NULL DEFAULT '0.00' COMMENT '价格（元）',
  `duration_days` int NOT NULL COMMENT '有效天数',
  `max_training_plans` int NOT NULL DEFAULT '3' COMMENT '最大训练计划数量',
  `unlock_all_exercises` tinyint(1) NOT NULL DEFAULT '0' COMMENT '解锁所有动作',
  `ai_recommendation` tinyint(1) NOT NULL DEFAULT '0' COMMENT 'AI推荐功能',
  `data_analysis` tinyint(1) NOT NULL DEFAULT '0' COMMENT '数据分析功能',
  `coach_service` tinyint(1) NOT NULL DEFAULT '0' COMMENT '教练服务',
  `description` text COMMENT '等级描述',
  `features` json DEFAULT NULL COMMENT '功能列表',
  `limits` json DEFAULT NULL COMMENT '限制说明',
  `sort_order` int NOT NULL DEFAULT '0' COMMENT '排序',
  `is_active` tinyint(1) NOT NULL DEFAULT '1' COMMENT '是否启用',
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `memberships_slug_unique` (`slug`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 2. user_memberships（用户会员关系表）

```sql
CREATE TABLE `user_memberships` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `user_id` bigint unsigned NOT NULL,
  `membership_id` bigint unsigned NOT NULL,
  `order_id` varchar(255) DEFAULT NULL COMMENT '订单ID',
  `started_at` timestamp NULL DEFAULT NULL COMMENT '生效时间',
  `expires_at` timestamp NULL DEFAULT NULL COMMENT '过期时间',
  `is_active` tinyint(1) NOT NULL DEFAULT '1' COMMENT '是否激活',
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `user_memberships_membership_id_foreign` (`membership_id`),
  KEY `user_memberships_user_id_is_active_index` (`user_id`,`is_active`),
  CONSTRAINT `user_memberships_membership_id_foreign` FOREIGN KEY (`membership_id`) REFERENCES `memberships` (`id`) ON DELETE CASCADE,
  CONSTRAINT `user_memberships_user_id_foreign` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**⚠️ 重要：会员等级获取逻辑（v2.1.0修复）**

该API采用**双重查询策略**确保会员等级正确识别：

1. **优先查询** `user_memberships` 表（标准方式）
   - 如果找到记录 → 返回 `membership.slug` 和完整信息
   
2. **后备查询** `users.membership_tier` 字段
   - 如果 `user_memberships` 表无记录 → 从 `users` 表读取
   - 自动标准化：`newbie` → `free`
   - 根据 tier 返回对应权限配置

**权限映射规则**：
```php
'free'      → AI推荐❌ 数据分析❌ 教练服务❌
'warmheart' → AI推荐✅ 数据分析✅ 教练服务❌
'energy'    → AI推荐✅ 数据分析✅ 教练服务✅
```

**典型场景**：
- 测试用户（UserSeeder创建）→ 只有 `users.membership_tier`
- 正式用户（完整注册流程）→ 有 `user_memberships` 记录

# 在AI对话前检查权限

### 配置说明

为满足合规要求，会员系统支持配置开关，可以在不修改代码的情况下启用/禁用会员功能。

**配置文件**: `config/membership.php`

```php
return [
    // 会员系统总开关
    'enabled' => env('MEMBERSHIP_ENABLED', true),
    
    // 功能开关
    'features' => [
        'payment' => env('MEMBERSHIP_PAYMENT_ENABLED', false),  // 支付功能
        'upgrade' => env('MEMBERSHIP_UPGRADE_ENABLED', true),   // 升级功能
        'trial' => env('MEMBERSHIP_TRIAL_ENABLED', true),       // 试用功能
    ],
    
    // 默认会员等级
    'default_tier' => env('MEMBERSHIP_DEFAULT_TIER', 'free'),
];
```

**环境变量配置**:

```bash
# .env 或 .env.production
MEMBERSHIP_ENABLED=true              # 启用会员系统
MEMBERSHIP_PAYMENT_ENABLED=false     # 禁用支付功能（合规要求）
MEMBERSHIP_UPGRADE_ENABLED=true      # 启用升级功能
MEMBERSHIP_TRIAL_ENABLED=true        # 启用试用功能
MEMBERSHIP_DEFAULT_TIER=free         # 默认会员等级
```

### 使用方式

**在Controller中检查配置**:

```php
use Illuminate\Support\Facades\Config;

public function upgrade(Request $request)
{
    // 检查会员系统是否启用
    if (!Config::get('membership.enabled')) {
        return response()->json([
            'code' => 403,
            'msg' => '会员系统暂未开放'
        ], 403);
    }
    
    // 检查支付功能是否启用
    if (!Config::get('membership.features.payment')) {
        return response()->json([
            'code' => 403,
            'msg' => '支付功能暂未开放'
        ], 403);
    }
    
    // 继续处理升级逻辑
}
```

**在Service中检查配置**:

```php
public function canUpgrade(int $userId): bool
{
    // 检查会员系统和升级功能是否启用
    return Config::get('membership.enabled') 
        && Config::get('membership.features.upgrade');
}
```

### 合规场景

**场景1：初期运营（无支付资质）**
```bash
MEMBERSHIP_ENABLED=true
MEMBERSHIP_PAYMENT_ENABLED=false     # 禁用支付
MEMBERSHIP_UPGRADE_ENABLED=false     # 禁用升级
```

**场景2：获得支付资质后**
```bash
MEMBERSHIP_ENABLED=true
MEMBERSHIP_PAYMENT_ENABLED=true      # 启用支付
MEMBERSHIP_UPGRADE_ENABLED=true      # 启用升级
```

**场景3：完全禁用会员系统**
```bash
MEMBERSHIP_ENABLED=false             # 所有用户使用免费版
```

## 📊 用量追踪与打赏奖励系统（v3.0.0新增）

### 系统概述

用量追踪系统记录用户使用AI对话、训练计划生成等功能的次数，并支持打赏奖励机制。

### 数据库结构

#### usage_stats 表

```sql
CREATE TABLE `usage_stats` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `user_id` bigint unsigned NOT NULL,
  `feature` varchar(50) NOT NULL COMMENT '功能标识',
  `count` int NOT NULL DEFAULT '0' COMMENT '使用次数',
  `date` date NOT NULL COMMENT '统计日期',
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `usage_stats_user_feature_date_unique` (`user_id`,`feature`,`date`),
  KEY `usage_stats_user_id_foreign` (`user_id`),
  CONSTRAINT `usage_stats_user_id_foreign` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**支持的功能标识**:
- `ai_chat` - AI对话
- `training_plan` - 训练计划生成
- `data_analysis` - 数据分析
- `exercise_recommendation` - 动作推荐

#### credit_logs 表（打赏奖励）

```sql
CREATE TABLE `credit_logs` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `user_id` bigint unsigned NOT NULL,
  `amount` int NOT NULL COMMENT '积分变动',
  `type` varchar(50) NOT NULL COMMENT '类型：reward/consume/refund',
  `reason` varchar(255) DEFAULT NULL COMMENT '原因说明',
  `related_id` bigint unsigned DEFAULT NULL COMMENT '关联ID',
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `credit_logs_user_id_foreign` (`user_id`),
  CONSTRAINT `credit_logs_user_id_foreign` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```
