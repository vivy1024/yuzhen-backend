## 🔍 详细表结构

### 1. users 表

**用途**：用户基础信息  
**前端类型**：`yuzhen_fitness_v2/src/types/auth.ts::UserInfo`

```sql
CREATE TABLE `users` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `name` varchar(255) NOT NULL,
  `email` varchar(255) NOT NULL UNIQUE,
  `phone` varchar(255) NULL,
  `avatar` varchar(255) NULL,
  `role` varchar(255) NOT NULL DEFAULT 'user',
  `status` varchar(1) NOT NULL DEFAULT '1' COMMENT '状态：1正常/0禁用',
  `del_flag` varchar(1) NOT NULL DEFAULT '0' COMMENT '删除标志',
  `is_active` tinyint(1) NOT NULL DEFAULT 1,
  `last_login_at` timestamp NULL,
  `membership_tier` varchar(255) NOT NULL DEFAULT 'newbie',
  `preferences` json NULL COMMENT '用户偏好设置',
  `favorites` json NULL COMMENT '收藏的动作ID列表',
  `exercise_reviews` json NULL COMMENT '动作评价',
  `email_verified_at` timestamp NULL,
  `onboarding_completed` tinyint(1) NOT NULL DEFAULT 0,
  `profile_completed_at` timestamp NULL,
  `password` varchar(255) NOT NULL,
  `remember_token` varchar(100) NULL,
  `created_at` timestamp NULL,
  `updated_at` timestamp NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**与前端类型对应**：
- ✅ `id` → `UserInfo.id`
- ✅ `name` → `UserInfo.nickname`
- ✅ `email` → `UserInfo.email`
- ✅ `phone` → `UserInfo.phone`
- ✅ `avatar` → `UserInfo.avatar`
- ✅ `role` → `UserInfo.roles`
- ✅ `preferences` → JSON结构
- ✅ `favorites` → JSON数组
- ✅ `last_login_at` → `UserInfo.last_login_at`

### 2. user_profiles 表（核心！）

**用途**：用户完整档案（JSON结构）  
**前端类型**：`yuzhen_fitness_v2/src/types/user-profile.ts::UserProfile`

```sql
CREATE TABLE `user_profiles` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `user_id` bigint unsigned NOT NULL UNIQUE,
  
  -- JSON字段：核心数据结构
  `basic_info` json NULL COMMENT 'BasicInfo: age, gender, height, weight',
  `fitness_goals` json NULL COMMENT 'FitnessGoals: primary_goals, target_weight',
  `training_preferences` json NULL COMMENT 'TrainingPreferences: training_split, equipment',
  `health_status` json NULL COMMENT 'HealthStatus: injuries, chronic_diseases',
  `nutrition_profile` json NULL COMMENT 'NutritionProfile: daily_calories, protein',
  `strength_data` json NULL COMMENT 'StrengthData: bench_press, squat, deadlift',
  `ffmi_assessment` json NULL COMMENT 'FFMIAssessment: ffmi, bmi, assessment',
  
  -- 元数据
  `version` int NOT NULL DEFAULT 1,
  `created_at` timestamp NULL,
  `updated_at` timestamp NULL,
  `last_sync_at` timestamp NULL,
  `sync_status` varchar(50) NOT NULL DEFAULT 'synced',
  `is_mcp_temp` tinyint(1) NOT NULL DEFAULT 0,
  `mcp_session_id` varchar(100) NULL,
  `sync_source` varchar(50) NULL,
  
  PRIMARY KEY (`id`),
  FOREIGN KEY (`user_id`) REFERENCES `users`(`id`) ON DELETE CASCADE,
  KEY `sync_status` (`sync_status`),
  KEY `is_mcp_temp` (`is_mcp_temp`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**与前端类型完全对应**：

| 数据库字段 | 前端TypeScript类型 | 说明 |
|-----------|-------------------|------|
| `basic_info` | `BasicInfo` | 年龄、性别、身高、体重等 |
| `fitness_goals` | `FitnessGoals` | 健身目标、目标体重、训练分化 |
| `training_preferences` | `TrainingPreferences` | 训练偏好、可用器械、场地 |
| `health_status` | `HealthStatus` | 健康状况、伤病史、用药 |
| `nutrition_profile` | `NutritionProfile` | 营养档案、热量、宏量营养素 |
| `strength_data` | `StrengthData` | 6大基础动作的1RM/3RM数据 |
| `ffmi_assessment` | `FFMIAssessment` | FFMI评估结果 |

### 3. exercises 表（核心！）

**用途**：动作库主表  
**前端类型**：`yuzhen_fitness_v2/src/types/exercise.ts::ExerciseDetail`

```sql
CREATE TABLE `exercises` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  
  -- 基础信息
  `name` varchar(255) NOT NULL COMMENT '动作名称（英文）',
  `name_zh` varchar(255) NULL COMMENT '动作名称（中文）',
  `slug` varchar(255) NOT NULL UNIQUE,
  `description` text NULL COMMENT '描述（英文）',
  `description_zh` text NULL COMMENT '描述（中文）',
  
  -- 动作要领（JSON数组）
  `correct_steps` json NULL COMMENT '正确步骤（英文）',
  `correct_steps_zh` json NULL COMMENT '正确步骤（中文）',
  
  -- 肌群相关
  `primary_muscle` varchar(255) NULL COMMENT '主要肌群',
  `secondary_muscles` json NULL COMMENT '次要肌群（数组）',
  
  -- 器械和难度
  `equipment` varchar(255) NULL,
  `difficulty` varchar(50) NULL,
  
  -- 动作类型
  `force_type` varchar(50) NULL COMMENT 'push/pull/static',
  `mechanic_type` varchar(50) NULL COMMENT 'compound/isolation',
  
  -- 分类和标签（JSON数组）
  `grips` json NULL,
  `categories` json NULL,
  `smart_tags` json NULL,
  
  -- 统计数据
  `rating` int NOT NULL DEFAULT 0,
  `view_count` int NOT NULL DEFAULT 0,
  
  `created_at` timestamp NULL,
  `updated_at` timestamp NULL,
  
  PRIMARY KEY (`id`),
  KEY `primary_muscle` (`primary_muscle`),
  KEY `equipment` (`equipment`),
  KEY `difficulty` (`difficulty`),
  KEY `view_count` (`view_count`),
  FULLTEXT KEY `search` (`name`, `name_zh`, `description`, `description_zh`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**当前数据**：1,603条记录

**与前端类型对应**：
- ✅ 字段名完全匹配（snake_case）
- ✅ JSON字段结构一致
- ✅ 支持多语言（_zh后缀）

### 4. chat_sessions 表（AI对话）

**用途**：对话记录（混合存储）  
**架构**：MySQL（结构化） + Qdrant（向量检索）

```sql
CREATE TABLE `chat_sessions` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `session_id` char(36) NOT NULL COMMENT '会话UUID',
  `user_id` bigint unsigned NULL COMMENT '用户ID（匿名为NULL）',
  `user_query` text NOT NULL,
  `llm_response` text NOT NULL,
  `model_used` varchar(50) NOT NULL,
  `tools_used` json NULL COMMENT '调用的工具列表',
  `metadata` json NULL COMMENT 'few_shot_count, orchestrator_used',
  `user_rating` tinyint NULL COMMENT '1-5星',
  `user_feedback` varchar(500) NULL,
  `qdrant_point_id` char(36) NULL COMMENT 'Qdrant向量点ID',
  `created_at` timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  PRIMARY KEY (`id`),
  FOREIGN KEY (`user_id`) REFERENCES `users`(`id`) ON DELETE SET NULL,
  KEY `idx_session_id` (`session_id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_created_at` (`created_at`),
  KEY `idx_model_used` (`model_used`),
  KEY `idx_qdrant_point_id` (`qdrant_point_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**混合存储架构**：
1. **MySQL**：存储结构化数据，支持快速查询
2. **Qdrant**：存储向量化对话，支持语义检索和Few-Shot学习
3. **关联**：通过`qdrant_point_id`字段关联
