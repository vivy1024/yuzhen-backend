## 🚀 执行迁移

### 方式一：一次性执行所有迁移（推荐用于测试环境）

```bash
# 进入后端目录
cd yuzhen-backend

# 执行所有待迁移
php artisan migrate

# 如果出错，回滚
php artisan migrate:rollback --step=5
```

### 方式二：逐个执行迁移（推荐用于生产环境）

```bash

# 验证：检查user_profiles表是否有basic_info等JSON字段
```

## ⚠️ 常见问题处理

### 问题1：迁移失败 - 字段已存在
```bash
# 错误信息：Column 'basic_info' already exists

# 解决方案：
# 1. 检查是否之前已运行过迁移
php artisan migrate:status

# 2. 如果确认要重新迁移，先回滚
php artisan migrate:rollback --step=1

# 3. 然后重新执行
php artisan migrate
```

### 问题2：外键约束失败
```bash
# 错误信息：Cannot add foreign key constraint

# 解决方案：
# 1. 检查关联表数据是否存在
SELECT * FROM training_plans WHERE id NOT IN (SELECT DISTINCT plan_id FROM training_sessions WHERE plan_id IS NOT NULL);

# 2. 清理无效数据
DELETE FROM training_sessions WHERE plan_id NOT IN (SELECT id FROM training_plans);

# 3. 重新执行迁移
```

### 问题3：JSON字段数据格式错误
```bash
# 错误信息：Invalid JSON text

# 解决方案：
# 1. 检查现有数据
SELECT id, basic_info FROM user_profiles WHERE JSON_VALID(basic_info) = 0;

# 2. 修复数据
UPDATE user_profiles 
SET basic_info = NULL 
WHERE JSON_VALID(basic_info) = 0;

# 3. 或手动修复
UPDATE user_profiles 
SET basic_info = '{}' 
WHERE basic_info IS NULL OR basic_info = '';
```

### 问题4：重命名字段失败
```bash
# 错误信息：Unknown column 'training_plan_id'

# 解决方案：
# Laravel的renameColumn依赖doctrine/dbal包

# 1. 确保已安装
composer require doctrine/dbal

# 2. 重新执行迁移
php artisan migrate
```
