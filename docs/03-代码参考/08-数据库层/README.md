## 🔄 数据同步机制

### MySQL → Neo4j同步

```
数据变更 → 触发事件 → 同步脚本 → Neo4j更新
```

### 同步策略

- **实时同步**: 关键数据变更
- **批量同步**: 定期全量同步
- **增量同步**: 只同步变更数据

## 🔍 查询优化

### 索引策略

```sql
-- 用户查询优化
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_phone ON users(phone);

-- 训练记录查询优化
CREATE INDEX idx_sessions_user_date ON training_sessions(user_id, session_date);
CREATE INDEX idx_plans_user ON training_plans(user_id);
```

### 查询优化技巧

1. **使用索引**: 为常用查询字段创建索引
2. **避免N+1**: 使用预加载（Eager Loading）
3. **分页查询**: 大数据集使用分页
4. **缓存结果**: 热点数据使用Redis缓存
