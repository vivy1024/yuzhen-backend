## 🎯 核心原则

### 1. 字段命名规范

**统一使用 `snake_case`**
```typescript
✅ 正确: user_id, created_at, fitness_level, primary_muscle
❌ 错误: userId, createdAt, fitnessLevel, primaryMuscle
```

**原因**:
- PHP/Laravel生态默认使用snake_case
- 数据库字段名使用snake_case
- 避免前后端转换开销

### 2. 数据结构规范

**复杂数据使用JSON字段存储**
```sql
-- ✅ 正确：使用JSON存储嵌套结构
basic_info JSON NULL,
fitness_goals JSON NULL,
training_preferences JSON NULL

-- ❌ 错误：扁平化存储复杂结构
nickname VARCHAR(255),
age INT,
gender VARCHAR(10),
...（字段过多）
```

**原因**:
- 保持数据结构完整性
- 便于版本升级
- 减少数据库字段数量

### 3. 时间格式标准

**统一使用 ISO 8601 格式**
```typescript
✅ 正确: "2025-11-01T10:30:00.000Z"
❌ 错误: "2025-11-01 10:30:00" 或时间戳
```

**实现方式**:
```php
// PHP Resource中统一使用
'created_at' => $this->created_at?->toISOString(),
'updated_at' => $this->updated_at?->toISOString(),
```

### 4. 布尔值规范

**统一使用布尔类型**
```typescript
✅ 正确: true, false
❌ 错误: 1, 0, "true", "false"
```

**实现方式**:
```php
// Model中使用casts
protected $casts = [
    'is_active' => 'boolean',
    'auto_renew' => 'boolean',
];
```

### 5. 空值处理规范

**统一使用 `null` 而非空字符串**
```typescript
✅ 正确: avatar: null
❌ 错误: avatar: ""
```

### 1. 用户档案系统 (UserProfile)

#### 数据库结构
```sql
CREATE TABLE user_profiles (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT UNSIGNED NOT NULL UNIQUE,
    
    -- 完整档案数据（JSON存储）
    basic_info JSON NULL COMMENT '基础信息',
    fitness_goals JSON NULL COMMENT '健身目标',
    training_preferences JSON NULL COMMENT '训练偏好',
    strength_data JSON NULL COMMENT '力量数据',
    health_status JSON NULL COMMENT '健康状况',
    nutrition_profile JSON NULL COMMENT '营养档案',
    ffmi_assessment JSON NULL COMMENT 'FFMI评估',
    
    -- 版本控制
    version INT NOT NULL DEFAULT 1 COMMENT '版本号',
    
    -- 时间戳
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

#### TypeScript类型（前端）
```typescript
interface UserProfile {

```

### 2. 训练计划系统 (TrainingPlan)

#### 数据库结构
```sql
CREATE TABLE training_plans (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT UNSIGNED NOT NULL,
    
    -- 基本信息
    name VARCHAR(255) NOT NULL COMMENT '计划名称',
    description TEXT NULL COMMENT '计划描述',
    type VARCHAR(50) NOT NULL DEFAULT 'manual' COMMENT '类型: template/ai_generated/manual',
    source_template_id BIGINT UNSIGNED NULL COMMENT '来源模板ID',
    
    -- 周期化结构（JSON存储）
    phases JSON NULL COMMENT '周期化阶段',
    weekly_schedule JSON NULL COMMENT '周训练安排',
    
    -- 统计信息
    total_weeks INT NULL COMMENT '总周数',
    total_sessions INT NULL COMMENT '总训练次数',
    stats JSON NULL COMMENT '统计信息',
    
    -- 状态
    status VARCHAR(50) NOT NULL DEFAULT 'active' COMMENT 'active/completed/archived',
    is_active BOOLEAN NOT NULL DEFAULT FALSE COMMENT '是否为当前使用计划',
    
    -- 时间戳
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_active (user_id, is_active)
);
```

#### TypeScript类型（前端）
```typescript

interface PlannedExercise {
```

### 3. 训练会话系统 (TrainingSession)

#### 数据库结构
```sql
CREATE TABLE training_sessions (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT UNSIGNED NOT NULL,
    plan_id BIGINT UNSIGNED NULL COMMENT '关联训练计划ID',
    
    -- 位置信息
    week INT NULL COMMENT '第几周',
    day INT NULL COMMENT '第几天',
    
    -- 时间信息
    date DATE NOT NULL COMMENT '训练日期',
    start_time TIMESTAMP NOT NULL COMMENT '开始时间',
    end_time TIMESTAMP NULL COMMENT '结束时间',
    
    -- 训练数据（JSON存储）
    exercises JSON NULL COMMENT '动作记录',
    
    -- 统计信息
    total_volume DECIMAL(10,2) NULL COMMENT '总容量(kg)',
    total_sets INT NULL COMMENT '总组数',
    avg_rpe DECIMAL(3,1) NULL COMMENT '平均RPE',
    
    -- 状态
    status VARCHAR(50) NOT NULL DEFAULT 'planning' COMMENT 'planning/in-progress/completed/abandoned',
    
    -- 备注
    notes TEXT NULL,
    
    -- 时间戳
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (plan_id) REFERENCES training_plans(id) ON DELETE SET NULL,
    INDEX idx_user_date (user_id, date)
);
```

#### TypeScript类型（前端）
```typescript
interface TrainingSession {
  id: string
  user_id: string
  plan_id?: string
  week?: number
  day?: number
  date: string
  start_time: string
  end_time?: string
  exercises: ExerciseRecord[]
  total_volume?: number
  total_sets?: number
  avg_rpe?: number
  status: 'planning' | 'in-progress' | 'completed' | 'abandoned'
  notes?: string
  synced?: boolean  // 前端专用，不存数据库
  created_at: string
  updated_at: string
}

interface ExerciseRecord {
  exercise_id: number
  exercise_name: string
  target_sets: number
  sets: SetRecord[]
  notes?: string
  order?: number
}

interface SetRecord {
  set_number: number
  weight: number | null
  reps: number | null
  rpe?: number
  rest_time?: number
  completed: boolean
  notes?: string
  recorded_at?: string
}
```

### 4. 动作库系统 (Exercise)

#### 字段标准
```typescript
// 统一使用单数形式
primary_muscle: string  // ✅ 统一标准
secondary_muscles: string[]  // ✅ 复数表示数组
```

#### 数据库结构
```sql
CREATE TABLE exercises (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    
    -- 基本信息
    name VARCHAR(255) NOT NULL,
    name_zh VARCHAR(255) NULL,
    slug VARCHAR(255) NOT NULL UNIQUE,
    description TEXT NULL,
    description_zh TEXT NULL,
    
    -- 分类信息（统一使用单数）
    primary_muscle VARCHAR(100) NULL COMMENT '主要肌肉（单数）',
    equipment VARCHAR(100) NULL COMMENT '所需器械',
    difficulty VARCHAR(50) NULL COMMENT '难度等级',
    force_type VARCHAR(50) NULL COMMENT '发力类型',
    mechanic_type VARCHAR(50) NULL COMMENT '运动类型',
    
    -- 数组类型（JSON存储）
    secondary_muscles JSON NULL COMMENT '次要肌肉群',
    grips JSON NULL COMMENT '握法',
    categories JSON NULL COMMENT '分类标签',
    
    -- 统计信息
    rating INT NOT NULL DEFAULT 0,
    view_count INT NOT NULL DEFAULT 0,
    
    -- 时间戳
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    
    INDEX idx_muscle (primary_muscle),
    INDEX idx_equipment (equipment),
    INDEX idx_difficulty (difficulty)
);
```

### 5. 会员系统 (Membership)

#### 数据库结构
```sql
CREATE TABLE memberships (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    
    -- 基本信息
    name VARCHAR(100) NOT NULL,
    slug VARCHAR(50) NOT NULL UNIQUE,
    tier VARCHAR(50) NOT NULL COMMENT 'free/warmheart/energy',
    
    -- 价格信息
    price DECIMAL(10,2) NOT NULL DEFAULT 0,
    duration_days INT NOT NULL,
    
    -- 描述
    description TEXT NULL,
    
    -- 功能配置（JSON存储）
    features JSON NULL COMMENT '功能列表',
    limits JSON NULL COMMENT '使用限制',
    
    -- 状态
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    sort_order INT NOT NULL DEFAULT 0,
    
    -- 时间戳
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL
);

CREATE TABLE user_memberships (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT UNSIGNED NOT NULL,
    membership_id BIGINT UNSIGNED NOT NULL,
    
    -- 会员信息
    tier VARCHAR(50) NOT NULL COMMENT '会员等级',
    
    -- 订阅信息
    start_date TIMESTAMP NOT NULL,
    end_date TIMESTAMP NULL,
    auto_renew BOOLEAN NOT NULL DEFAULT FALSE,
    
    -- 使用统计（JSON存储）
    usage_stats JSON NULL COMMENT '使用统计',
    
    -- 状态
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    
    -- 时间戳
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (membership_id) REFERENCES memberships(id) ON DELETE RESTRICT
);
```

## 🔧 Resource转换规范

### 统一Resource基类
```php
<?php

namespace App\Http\Resources;

use Illuminate\Http\Resources\Json\JsonResource;

abstract class BaseResource extends JsonResource
{
    /**
     * 转换时间为ISO 8601格式
     */
    protected function formatTimestamp($timestamp): ?string
    {
        return $timestamp?->toISOString();
    }

    /**
     * 转换为布尔值
     */
    protected function toBoolean($value): bool
    {
        return (bool) $value;
    }

    /**
     * 格式化价格
     */
    protected function formatPrice($price): float
    {
        return (float) $price;
    }
}
```

### Resource示例
```php
class UserProfileResource extends BaseResource
{
    public function toArray(Request $request): array
    {
        return [
            'user_id' => $this->user_id,
            'basic_info' => $this->basic_info,
            'fitness_goals' => $this->fitness_goals,
            'training_preferences' => $this->training_preferences,
            'strength_data' => $this->strength_data,
            'health_status' => $this->health_status,
            'nutrition_profile' => $this->nutrition_profile,
            'ffmi_assessment' => $this->ffmi_assessment,
            'version' => $this->version,
            'created_at' => $this->formatTimestamp($this->created_at),
            'updated_at' => $this->formatTimestamp($this->updated_at),
        ];
    }
}
```

## ✅ 验证检查清单

### 开发前检查
- [ ] 字段名使用snake_case
- [ ] 复杂数据使用JSON字段
- [ ] 时间字段返回ISO 8601格式
- [ ] 布尔值使用true/false而非1/0
- [ ] 空值使用null而非空字符串

### 数据库迁移检查
- [ ] 字段类型正确（JSON、TIMESTAMP等）
- [ ] 添加必要的索引
- [ ] 添加外键约束
- [ ] 添加字段注释

### Model检查
- [ ] $fillable包含所有可填充字段
- [ ] $casts正确转换JSON和布尔类型
- [ ] 关联关系正确定义

### Resource检查
- [ ] 字段名与前端完全一致
- [ ] 时间使用toISOString()转换
- [ ] 布尔值正确转换
- [ ] 移除不需要的字段
