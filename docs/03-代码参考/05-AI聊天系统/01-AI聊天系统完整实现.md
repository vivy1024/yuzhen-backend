## 📋 概述

AI聊天系统是玉珍健身应用的核心功能，实现了前端PWA、PHP后端、DAML-RAG服务的三端打通架构。系统支持流式响应、历史对话管理、多轮对话上下文、工具调用可视化等功能。

### 核心特性

- ✅ **三端打通架构**: 前端PWA ↔ PHP后端 ↔ DAML-RAG服务
- ✅ **流式响应**: Server-Sent Events (SSE) 实时流式输出
- ✅ **历史对话管理**: 话题分组、消息持久化、会话恢复
- ✅ **多轮对话上下文**: 基于话题ID的上下文管理
- ✅ **工具调用可视化**: DAG执行流程、工具调用时间线
- ✅ **双存储策略**: IndexedDB本地缓存 + MySQL后端持久化
- ✅ **游客模式支持**: 未登录用户可使用AI聊天（本地存储）

### 技术栈

| 层级 | 技术 | 说明 |
|-----|------|------|
| **前端** | Vue 3 + TypeScript | PWA应用 |
| **状态管理** | Pinia | 聊天状态、流式状态 |
| **本地存储** | IndexedDB | 游客模式消息缓存 |
| **后端** | Laravel 10 + PHP 8.2 | API代理层 |
| **AI服务** | DAML-RAG (FastAPI) | 智能问答引擎 |
| **数据库** | MySQL 8.4 | 对话历史持久化 |

### 数据流

#### 1. 用户发送消息流程

```
用户输入消息
  ↓
前端chatStore.sendMessage()
  ├─ 创建用户消息
  ├─ 保存到IndexedDB（本地缓存）
  ├─ 登录用户：保存到后端MySQL
  └─ 创建AI消息占位符
  ↓
useChatStream.startStream()
  ├─ 建立SSE连接: POST /api/ai/v1/chat/stream
  ├─ 传递参数: userId, query, sessionId, topicId, strategy
  └─ 订阅流式状态更新
  ↓
PHP AiProxyController.streamChat()
  ├─ 接收前端请求
  ├─ 使用cURL代理到DAML-RAG
  └─ 流式转发响应（SSE格式）
  ↓
DAML-RAG /api/v1/chat/stream
  ├─ 执行11步工作流程
  ├─ 流式输出: content, dag_execution, training_plan等
  └─ 调用PHP后端保存对话
  ↓
PHP InternalChatController.saveChatSession()
  ├─ 保存到chat_sessions表（Few-Shot学习）
  └─ 返回session_id
  ↓
前端接收流式响应
  ├─ 实时更新AI消息内容
  ├─ 解析structuredData（工具调用、训练计划）
  ├─ 流式完成后保存到IndexedDB
  ├─ 登录用户：保存到后端MySQL
  └─ 更新话题信息
```

#### 2. 历史对话加载流程

```
用户打开聊天页面
  ↓
前端chatStore.loadMessages(topicId)
  ├─ 优先从IndexedDB获取（本地缓存）
  ├─ 如果IndexedDB为空且用户已登录
  │   └─ 调用后端API: GET /api/chat/topics/{id}/messages
  └─ 渲染消息列表
```

## 💾 数据库设计

### 1. chat_topics 表（话题表）

用于组织和管理用户的AI对话，将多轮对话归类到话题下。

```sql
CREATE TABLE `chat_topics` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `user_id` bigint unsigned NOT NULL COMMENT '用户ID',
  `name` varchar(255) NOT NULL COMMENT '话题名称',
  `description` text COMMENT '话题描述',
  `message_count` int NOT NULL DEFAULT '0' COMMENT '消息数量',
  `last_message` text COMMENT '最后一条消息',
  `last_message_at` timestamp NULL DEFAULT NULL COMMENT '最后消息时间',
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  `deleted_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `chat_topics_user_id_foreign` (`user_id`),
  KEY `idx_last_message_at` (`last_message_at`),
  CONSTRAINT `chat_topics_user_id_foreign` FOREIGN KEY (`user_id`) 
    REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**字段说明**：
- `user_id`: 关联用户ID，外键约束
- `name`: 话题名称，用于显示在侧边栏
- `message_count`: 消息计数，用于显示对话轮数
- `last_message`: 最后一条消息预览
- `last_message_at`: 最后消息时间，用于排序

```php
// app/Http/Controllers/AiProxyController.php
public function streamChat(Request $request): StreamedResponse
{
    $data = $request->all();
    
    return new StreamedResponse(function () use ($data) {
        $url = "{$this->damlRagUrl}/api/v1/chat/stream";
        
        $ch = curl_init();
        curl_setopt_array($ch, [
            CURLOPT_URL => $url,
            CURLOPT_POST => true,
            CURLOPT_POSTFIELDS => json_encode($data),
            CURLOPT_HTTPHEADER => [
                'Content-Type: application/json',
                'Accept: text/event-stream',
            ],
            CURLOPT_RETURNTRANSFER => false,
            CURLOPT_WRITEFUNCTION => function ($ch, $chunk) {
                echo $chunk;
                ob_flush();
                flush();
                return strlen($chunk);
            },
            CURLOPT_TIMEOUT => 300,
        ]);
        
        curl_exec($ch);
        curl_close($ch);
    }, 200, [
        'Content-Type' => 'text/event-stream',
        'Cache-Control' => 'no-cache',
        'Connection' => 'keep-alive',
        'X-Accel-Buffering' => 'no',
    ]);
}
```

```php
// app/Modules/Chat/Controllers/InternalChatController.php
public function saveChatSession(Request $request): JsonResponse
{
    $validator = Validator::make($request->all(), [
        'session_id' => 'required|string|max:36',
        'user_id' => 'nullable|integer|exists:users,id',
        'user_query' => 'required|string|max:10000',
        'llm_response' => 'required|string|max:50000',
        'model_used' => 'required|string|max:50',
        'tools_used' => 'nullable|array',
        'metadata' => 'nullable|array',
        'qdrant_point_id' => 'nullable|string|max:36',
    ]);

    if ($validator->fails()) {
        return response()->json([
            'code' => 422,
            'msg' => '验证失败',
            'data' => ['errors' => $validator->errors()]
        ], 422);
    }

    $chatSession = ChatSession::create([
        'session_id' => $request->session_id,
        'user_id' => $request->user_id,
        'user_query' => $request->user_query,
        'llm_response' => $request->llm_response,
        'model_used' => $request->model_used,
        'tools_used' => $request->tools_used,
        'metadata' => $request->metadata,
        'qdrant_point_id' => $request->qdrant_point_id,
    ]);

    return response()->json([
        'code' => 200,
        'msg' => '保存成功',
        'data' => [
            'id' => $chatSession->id,
            'session_id' => $chatSession->session_id,
            'created_at' => $chatSession->created_at->toIso8601String(),
        ]
    ]);
}
```

```typescript
export function useChatStream() {
  const isStreaming = ref(false)
  const streamedContent = ref('')
  const structuredData = ref<any[]>([])
  const currentSessionId = ref<string | null>(null)
  
  async function startStream(params: {
    userId: string
    query: string
    sessionId?: string
    topicId?: string
    strategy?: 'dag' | 'agent'
  }) {
    isStreaming.value = true
    streamedContent.value = ''
    structuredData.value = []
    
    const url = `${API_BASE_URL}/api/ai/v1/chat/stream`
    
    const response = await fetch(url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`
      },
      body: JSON.stringify({
        user_id: params.userId,
        query: params.query,
        session_id: params.sessionId,
        topic_id: params.topicId,
        strategy: params.strategy || 'dag',
        domain: 'fitness'
      })
    })
    
    const reader = response.body!.getReader()
    const decoder = new TextDecoder()
    
    while (true) {
      const { done, value } = await reader.read()
      if (done) break
      
      const chunk = decoder.decode(value)
      const lines = chunk.split('\n')
      
      for (const line of lines) {
        if (line.startsWith('data: ')) {
          const data = JSON.parse(line.slice(6))
          
          if (data.type === 'content') {
            streamedContent.value += data.content
          } else if (data.type === 'dag_execution') {
            structuredData.value.push(data)
          } else if (data.type === 'training_plan') {
            structuredData.value.push(data)
          } else if (data.type === 'session_id') {
            currentSessionId.value = data.session_id
          } else if (data.type === 'done') {
            break
          }
        }
      }
    }
    
    isStreaming.value = false
  }
  
  return {
    isStreaming,
    streamedContent,
    structuredData,
    currentSessionId,
    startStream
  }
}
```

```typescript
    })
    
    // 标记流式错误
    streamingStore.markError(error.message)
  } finally {
    isStreaming.value = false
  }
}
```

## 🐛 故障排查

### 1. 流式响应中断

**症状**: AI回复突然停止，没有完整输出

**可能原因**:
- PHP后端超时（默认300秒）
- DAML-RAG服务异常
- 网络连接中断

**排查步骤**:
```bash
# 1. 检查PHP后端日志
docker logs fitness_php_v2 --tail 100

# 2. 检查DAML-RAG日志
docker logs fitness_daml_rag --tail 100

# 3. 检查网络连接
curl -X POST http://localhost:8001/api/v1/chat/stream \
  -H "Content-Type: application/json" \
  -d '{"user_id":"123","query":"测试"}'
```

**解决方案**:
- 增加PHP超时时间（`php.ini`: `max_execution_time=600`）
- 检查DAML-RAG服务健康状态
- 重启相关服务

### 2. 历史对话加载失败

**症状**: 打开聊天页面，历史消息不显示

**可能原因**:
- IndexedDB被清除
- 后端API异常
- 数据库连接失败

**排查步骤**:
```bash
# 1. 检查IndexedDB（浏览器开发者工具）
Application → IndexedDB → ChatHistoryDB

# 2. 检查后端API
curl http://localhost:9000/api/chat/topics/1/messages \
  -H "Authorization: Bearer <token>"

# 3. 检查MySQL连接
docker exec fitness_mysql mysql -u root -p -e "SELECT COUNT(*) FROM chat_messages;"
```

**解决方案**:
- 清除浏览器缓存后重新登录
- 检查后端API日志
- 验证数据库连接配置

### 3. 消息保存失败

**症状**: 发送消息后，刷新页面消息丢失

**可能原因**:
- IndexedDB写入失败
- 后端API保存失败
- 数据库写入异常

**排查步骤**:
```javascript
// 1. 检查IndexedDB写入
await chatHistoryDB.saveMessage({...})
  .then(() => console.log('保存成功'))
  .catch(err => console.error('保存失败:', err))

// 2. 检查后端API
const response = await topicApi.saveTopicMessage(topicId, {...})
console.log('后端响应:', response)

// 3. 检查数据库
SELECT * FROM chat_messages ORDER BY created_at DESC LIMIT 10;
```

**解决方案**:
- 检查浏览器存储配额
- 验证后端API权限
- 检查数据库表结构
