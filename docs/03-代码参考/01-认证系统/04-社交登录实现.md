## 📋 模块概述

SocialLogin社交登录系统提供第三方平台（微信）的OAuth2.0登录功能。

**核心特点**:

## 🗄️ 核心Models

### SocialAccount.php

**表结构**:
```sql
CREATE TABLE social_accounts (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    provider VARCHAR(50),           -- 平台（wechat/qq/github等）
    provider_id VARCHAR(255),       -- 平台用户ID
    nickname VARCHAR(255),          -- 昵称
    name VARCHAR(255),
    email VARCHAR(255),
    avatar VARCHAR(255),            -- 头像URL
    access_token TEXT,              -- 访问令牌
    refresh_token TEXT,             -- 刷新令牌
    expires_in TIMESTAMP,           -- 令牌过期时间
    token_response JSON,            -- 完整令牌响应
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    
    UNIQUE KEY (provider, provider_id),
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

**核心方法**:
```php
// 关联用户
public function user(): BelongsTo

// 检查Token是否过期
public function isTokenExpired(): bool

// 刷新Token
public function refreshAccessToken(): bool

// 获取用户显示名称
public function getDisplayNameAttribute(): string
```

## 🔄 登录流程

### 微信登录完整流程

```
1. 前端：点击"微信登录"按钮
   调用 GET /api/social/wechat/redirect
   ↓
2. 后端：返回微信授权URL
   ↓
3. 前端：跳转到微信授权页面
   用户扫码确认授权
   ↓
4. 微信：回调后端
   GET /api/social/wechat/callback?code=xxx
   ↓
5. 后端：处理回调
   - 使用code换取access_token
   - 获取微信用户信息
   - 查找是否已有绑定的用户
   - 如果没有，创建新用户
   - 生成JWT Token
   ↓
6. 后端：重定向到前端并带上Token
   302 → https://app.yuzhen-fitness.cn/#/login/success?token=xxx
   ↓
7. 前端：保存Token，登录成功
```

## 🎯 前端集成示例

### 1. 微信登录按钮

```typescript
const loginWithWechat = async () => {
  // 获取微信授权URL
  const response = await api.get('/api/social/wechat/redirect');
  
  // 跳转到微信授权页面
  window.location.href = response.data.auth_url;
};

// 或者使用弹窗方式
const loginWithWechatPopup = () => {
  const popup = window.open(
    authUrl,
    'wechat_login',
    'width=500,height=600'
  );
  
  // 监听回调
  window.addEventListener('message', (event) => {
    if (event.data.token) {
      localStorage.setItem('auth_token', event.data.token);
      popup.close();
      router.push('/dashboard');
    }
  });
};
```

// 在登录成功页面

## 🔒 安全最佳实践

### 1. State参数防CSRF

```php
// 生成state
$state = Str::random(40);
session(['oauth_state' => $state]);

// 回调验证
if ($request->state !== session('oauth_state')) {
    throw new \Exception('Invalid state parameter');
}
```

### 2. Token安全存储

```php
// 加密存储access_token
$socialAccount->access_token = encrypt($accessToken);

// 使用时解密
$token = decrypt($socialAccount->access_token);
```

### 3. 定期刷新Token

```php
// 检查Token是否即将过期
if ($socialAccount->expires_in < now()->addMinutes(10)) {
    $socialAccount->refreshAccessToken();
}
```
