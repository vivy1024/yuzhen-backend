## 📋 模块概述

Auth认证系统负责用户登录、注册、Token管理等功能，采用JWT（JSON Web Token）无状态认证方式。

**核心特点**:
- ✅ JWT Token认证（无状态）
- ✅ 多标识符登录（用户名/邮箱/手机号）
- ✅ 双Token机制（访问Token + 刷新Token）
- ✅ 密码加密（bcrypt）
- ✅ 登录/登出事件
- ✅ 支持微信登录集成
- ✅ Token自动过期检测

### JwtService.php

**路径**: `app/Modules/Auth/Services/JwtService.php`

**核心方法**:

```php
// 生成访问令牌
public function generateToken(User $user): string

// 生成刷新令牌
public function generateRefreshToken(User $user): string

// 验证访问令牌
public function verifyToken(string $token): ?array

// 验证刷新令牌
public function verifyRefreshToken(string $token): ?array

// 从令牌中提取用户ID
public function getUserIdFromToken(string $token): ?int
```

**使用示例**:
```php
$jwtService = app(JwtService::class);

// 生成Token对
$accessToken = $jwtService->generateToken($user);
$refreshToken = $jwtService->generateRefreshToken($user);

// 验证访问令牌
$payload = $jwtService->verifyToken($accessToken);
// ['iss' => '...', 'iat' => 1729996400, 'exp' => 1730000000, 'user_id' => 1, 'username' => 'zhangsan', 'role' => 'user']

// 验证刷新令牌
$refreshPayload = $jwtService->verifyRefreshToken($refreshToken);
// ['iss' => '...', 'iat' => 1729996400, 'exp' => 1730600000, 'user_id' => 1, 'type' => 'refresh']
```

## 🛡️ Middleware

### JwtAuthenticate.php

**路径**: `app/Modules/Auth/Middleware/JwtAuthenticate.php`

**用途**: 验证JWT Token

**使用方式**:
```php
// 在路由中使用
Route::middleware('jwt.auth')->group(function () {
    Route::get('/api/user/profile', [UserController::class, 'profile']);
});

// 或在Controller中使用
public function __construct()
{
    $this->middleware('jwt.auth')->except(['login', 'register']);
}
```

**工作流程**:
```
1. 从请求头获取Token（Authorization: Bearer {token}）
   ↓
2. 验证Token格式和签名
   ↓
3. 检查Token是否过期
   ↓
4. 检查Token是否在黑名单中（可选）
   ↓
5. 解析Token获取用户ID
   ↓
6. 将用户信息注入到Request中
   ↓
7. 继续处理请求
```

## 🔐 JWT Token结构

### Token格式

```
eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJ1c2VyX2lkIjoxLCJleHAiOjE3MzAwMDAwMDB9.signature
│                                      │                                      │
│          Header (头部)               │         Payload (载荷)                │  Signature (签名)
```

### 访问Token Payload

```json
{
  "iss": "http://localhost:8000",  // 签发者
  "iat": 1729996400,               // 签发时间
  "exp": 1730000000,               // 过期时间（1小时）
  "user_id": 1,
  "username": "zhangsan",
  "role": "user"
}
```

### 刷新Token Payload

```json
{
  "iss": "http://localhost:8000",  // 签发者
  "iat": 1729996400,               // 签发时间
  "exp": 1730600000,               // 过期时间（7天）
  "user_id": 1,
  "type": "refresh"
}
```

### 配置（.env）

```env
JWT_SECRET=your-secret-key-here              # JWT密钥（生产环境必须修改）
JWT_TTL=3600                                # 访问Token有效期（1小时）
JWT_REFRESH_TTL=604800                      # 刷新Token有效期（7天）
```

## 🔄 认证流程

### 注册流程

```
1. 前端提交注册信息
   ↓
2. RegisterRequest验证数据
   ↓
3. AuthService::register()
   - 检查邮箱是否已存在
   - 加密密码（bcrypt）
   - 创建用户
   - 创建默认用户档案
   - 分配免费会员
   ↓
4. 生成JWT Token
   ↓
5. 触发UserRegistered事件
   ↓
6. 返回用户信息和Token
```

### 登录流程（多标识符支持）

```
1. 前端提交登录凭证
   identifier: 支持用户名/邮箱/手机号
   ↓
2. LoginRequest验证数据格式
   ↓
3. AuthService::login()
   - findUserByIdentifier() 查找用户
   - Hash::check() 验证密码
   - 检查用户状态(status=1)
   - updateLastLogin() 更新登录时间和IP
   ↓
4. JwtService生成Token对
   - generateToken() 生成访问Token(1小时)
   - generateRefreshToken() 生成刷新Token(7天)
   ↓
5. 触发UserLoggedIn事件
   ↓
6. 返回用户信息和Token对
```

### 认证请求流程

```
1. 前端发送带Token的请求
   Header: Authorization: Bearer {token}
   ↓
2. JwtAuthenticate中间件拦截
   ↓
3. JwtService验证Token
   - 检查格式
   - 验证签名
   - 检查过期时间
   ↓
4. 解析用户ID
   ↓
5. 查询用户信息
   ↓
6. 将用户注入到Request中
   auth()->user() 可获取当前用户
   ↓
7. 继续处理业务逻辑
```

## 📊 前后端对接

### 前端存储Token（双Token机制）

```typescript
// 登录成功后
const response = await api.post('/api/auth/login', {
  identifier: 'zhangsan',  // 支持多标识符
  password: 'password123'
});

// 存储Token对
localStorage.setItem('access_token', response.data.access_token);
localStorage.setItem('refresh_token', response.data.refresh_token);
localStorage.setItem('user', JSON.stringify(response.data.user));
```

### 请求时携带Token

```typescript
// 使用axios拦截器（自动携带访问Token）
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

### Token过期自动刷新

```typescript
// 响应拦截器 - 自动刷新Token
axios.interceptors.response.use(
  response => response,
  async error => {
    if (error.response?.status === 401) {
      // 访问Token过期，尝试刷新
      try {
        const refreshToken = localStorage.getItem('refresh_token');
        const refreshResponse = await api.post('/api/auth/refresh', {
          refresh_token: refreshToken
        });

        // 更新Token对
        localStorage.setItem('access_token', refreshResponse.data.access_token);
        localStorage.setItem('refresh_token', refreshResponse.data.refresh_token);

        // 重试原请求
        error.config.headers.Authorization = `Bearer ${refreshResponse.data.access_token}`;
        return axios.request(error.config);
      } catch (refreshError) {
        // 刷新失败，清除所有Token并跳转登录
        localStorage.removeItem('access_token');
        localStorage.removeItem('refresh_token');
        localStorage.removeItem('user');
        window.location.href = '/login';
      }
    }
    return Promise.reject(error);
  }
);
```

## 🔒 安全最佳实践

### 1. 密码安全

```php
// ✅ 正确：使用bcrypt加密
$hashedPassword = bcrypt($password);

// ✅ 验证密码
if (Hash::check($password, $user->password)) {
    // 密码正确
}

// ❌ 错误：明文存储
$user->password = $password;
```

### 2. Token存储

```typescript
// ✅ 推荐：使用httpOnly Cookie（更安全）
// 后端设置Cookie
response()->cookie('auth_token', $token, 60, '/', null, true, true);

// ✅ 可接受：localStorage（需注意XSS）
localStorage.setItem('auth_token', token);

// ❌ 不推荐：sessionStorage（刷新页面丢失）
sessionStorage.setItem('auth_token', token);
```

### 3. HTTPS强制

```nginx
# Nginx配置
server {
    listen 443 ssl;
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    # 强制HTTPS
    add_header Strict-Transport-Security "max-age=31536000" always;
}
```

### 4. Token刷新策略

```typescript
// 在Token过期前5分钟自动刷新
const checkAndRefreshToken = () => {
  const token = localStorage.getItem('auth_token');
  const payload = parseJwt(token);
  const expiresIn = payload.exp - Date.now() / 1000;
  
  if (expiresIn < 300) { // 小于5分钟
    refreshToken();
  }
};

setInterval(checkAndRefreshToken, 60000); // 每分钟检查
```

## 🔍 常见问题

### Q1: 如何在Controller中获取当前用户？

**A**:
```php
// 方法1：使用auth()辅助函数
$user = auth()->user();
$userId = auth()->id();

// 方法2：使用Request
$user = $request->user();
```

### Q2: Token过期时间如何设置？

**A**: 在 `.env` 中配置：
```env
JWT_TTL=3600  # 1小时
JWT_REFRESH_TTL=604800  # 7天
```

### Q3: 如何实现"记住我"功能？

**A**:
```php
// 登录时传入remember参数
$ttl = $request->remember ? 604800 : 3600; // 7天 或 1小时
$token = $jwtService->generateToken($userId, [], $ttl);
```
