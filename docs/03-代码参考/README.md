## 📝 文档编写规范

### 文档结构

每个代码参考文档应包含：

1. **概述** - 功能说明、技术选型
2. **核心代码** - 关键实现代码
3. **数据结构** - 数据模型、数据库表
4. **API接口** - 接口定义、参数说明
5. **使用示例** - 代码示例、调用方式
6. **注意事项** - 常见问题、最佳实践

### 代码示例规范

```php
/**
 * 功能说明
 * 
 * @param string $param 参数说明
 * @return array 返回值说明
 */
public function exampleMethod(string $param): array
{
    // 实现逻辑
    return [
        'success' => true,
        'data' => $result,
    ];
}
```
