## 📋 模块概述

Training训练系统负责管理用户的训练计划、训练会话、训练记录和进度追踪。

**核心特点**:
- ✅ 训练计划管理（创建、编辑、删除、激活）
- ✅ 训练会话记录
- ✅ 训练记录和历史
- ✅ 进度追踪和数据分析
- ✅ AI对话集成训练计划导入
- ✅ 智能训练计划解析和结构化存储
- ✅ 动作详情链接集成

**v2.0.0 更新内容**:
- ✅ **AI对话集成** - 新增从AI对话导入训练计划功能
- ✅ **智能解析器** - 新增训练计划文本解析服务
- ✅ **结构化存储** - 支持AI生成的动作、组数、次数等结构化数据
- ✅ **API端点扩展** - 新增 `POST /api/training-plans/ai-import` 端点
- ✅ **来源标记** - 支持标记训练计划来源（手动创建/AI生成）

**v1.1.0 历史更新**:
- ✅ 新增 `activate()` 方法 - 激活训练计划
- ✅ 新增 `update()` 方法 - 更新训练计划
- ✅ 新增 `destroy()` 方法 - 软删除训练计划
- ✅ 新增 `deactivateUserPlans()` 方法 - 停用用户其他计划
- ✅ 修复路由前缀与前端完全匹配

## 🗄️ 核心Models

### TrainingPlan.php

**表结构**:
```sql
CREATE TABLE training_plans (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    name VARCHAR(255),              -- 计划名称
    description TEXT,               -- 计划描述
    goal ENUM,                      -- 目标（增肌/减脂/塑形）
    duration_weeks INT,             -- 持续周数
    days_per_week INT,              -- 每周训练天数
    difficulty ENUM,                -- 难度
    is_public BOOLEAN DEFAULT 0,    -- 是否公开
    is_ai_generated BOOLEAN DEFAULT 0, -- AI生成
    status ENUM,                    -- 状态（active/completed/paused）
    started_at DATE,                -- 开始日期
    completed_at DATE,              -- 完成日期
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

**核心方法**:
```php
// 关联用户
public function user(): BelongsTo

// 关联训练会话
public function sessions(): HasMany

// 关联训练记录
public function records(): HasMany

// 检查是否激活
public function isActive(): bool

// 检查是否完成
public function isCompleted(): bool

// 计算完成百分比
public function getCompletionPercentage(): float

// 获取下一个训练日
public function getNextTrainingDay(): ?string

// 作用域：激活的计划
public function scopeActive($query)
```

### TrainingSession.php

**表结构**:
```sql
CREATE TABLE training_sessions (
    id BIGINT PRIMARY KEY,
    training_plan_id BIGINT,
    day_number INT,                 -- 第几天
    name VARCHAR(255),              -- 会话名称（如："胸部训练日"）
    exercises JSON,                 -- 动作列表（JSON）
    target_duration INT,            -- 目标时长（分钟）
    notes TEXT,
    display_order INT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    
    FOREIGN KEY (training_plan_id) REFERENCES training_plans(id)
);
```

**exercises JSON格式**:
```json

    "sets": 4,
    "reps": "8-12",

    "rest_seconds": 90,
    "notes": "注意肩胛骨收紧"
  },
  {
    "exercise_id": 5,
    "sets": 3,
    "reps": "10-15",
    "weight": 40,
    "rest_seconds": 60
  }
]
```

### TrainingRecord.php

**表结构**:
```sql
CREATE TABLE training_records (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    training_plan_id BIGINT,
    training_session_id BIGINT,
    exercise_id BIGINT,             -- 动作ID
    sets_completed INT,             -- 完成组数
    reps_completed INT,             -- 完成次数
    weight_used DECIMAL(5,2),       -- 使用重量
    duration_seconds INT,           -- 时长
    difficulty_rating INT,          -- 难度评分(1-5)
    notes TEXT,
    recorded_at TIMESTAMP,          -- 记录时间
    created_at TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (training_plan_id) REFERENCES training_plans(id)
);
```

### TrainingProgress.php

**表结构**:
```sql
CREATE TABLE training_progress (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    training_plan_id BIGINT,
    date DATE,                      -- 日期
    sessions_completed INT,         -- 完成会话数
    total_volume_kg INT,            -- 总训练量(kg)
    total_duration_minutes INT,     -- 总时长(分钟)
    body_weight DECIMAL(5,2),       -- 当天体重
    notes TEXT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

## 📊 数据分析

### 训练量计算

```php
// 总训练量 = Σ(组数 × 次数 × 重量)
$totalVolume = TrainingRecord::where('user_id', $userId)
    ->selectRaw('SUM(sets_completed * reps_completed * weight_used) as volume')
    ->first()
    ->volume;
```

### 进度图表数据

```php
// 每周训练量趋势
$weeklyVolume = TrainingProgress::where('user_id', $userId)
    ->selectRaw('YEAR(date) as year, WEEK(date) as week, SUM(total_volume_kg) as volume')
    ->groupBy('year', 'week')
    ->orderBy('year')
    ->orderBy('week')
    ->get();

// 用于前端图表
$chartData = $weeklyVolume->map(function ($item) {
    return [
        'week' => "{$item->year}年第{$item->week}周",
        'volume' => $item->volume
    ];
});
```

## 🤖 AI训练计划生成

### 会员权限要求

```php
// 检查会员权限
if (!$membershipService->checkPermission($userId, 'ai_recommendation')) {
    throw new \Exception('需要升级会员才能使用AI生成功能');
```

### 生成逻辑

```php
1. 获取用户档案（身高、体重、目标、水平）
2. 分析用户历史训练数据
3. 根据目标选择合适的动作组合
4. 计算训练量和强度
5. 生成周期性计划（含渐进式负荷）
6. 返回个性化训练计划
```
