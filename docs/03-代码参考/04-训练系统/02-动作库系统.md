## 🗄️ 数据库结构

### exercises（动作主表）

```sql
CREATE TABLE exercises (
    id BIGINT PRIMARY KEY,
    name VARCHAR(255),              -- 动作名称（英文）
    name_zh VARCHAR(255),           -- 动作名称（中文）
    slug VARCHAR(255) UNIQUE,       -- 唯一标识
    description TEXT,               -- 描述（英文）
    description_zh TEXT,            -- 描述（中文）
    primary_muscles VARCHAR(255),   -- 主要目标肌肉群
    equipment VARCHAR(255),         -- 所需器械
    difficulty VARCHAR(50),         -- 难度等级
    force_type VARCHAR(50),         -- 力量类型（推/拉/保持）
    mechanic_type VARCHAR(50),      -- 机制类型（复合/孤立）
    grips JSON,                     -- 握法（JSON数组）
    categories JSON,                -- 分类（JSON数组）
    rating INT DEFAULT 0,           -- 评分
    view_count INT DEFAULT 0,       -- 浏览次数
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);
```

### exercise_v2_media（媒体资源表）

```sql
CREATE TABLE exercise_v2_media (
    id BIGINT PRIMARY KEY,
    exercise_id BIGINT,
    media_type ENUM('image','video','thumbnail'),
    cdn_url VARCHAR(255),           -- CDN URL
    file_size INT,                  -- 文件大小（字节）
    duration INT,                   -- 视频时长（秒）
    display_order INT,              -- 显示顺序
    created_at TIMESTAMP,
    
    FOREIGN KEY (exercise_id) REFERENCES exercises(id)
);
```

### instructions（指导步骤表）

```sql
CREATE TABLE instructions (
    id BIGINT PRIMARY KEY,
    exercise_id BIGINT,
    instruction_type ENUM('execution','tips','mistakes'), -- 执行/技巧/避坑
    step_number INT,                -- 步骤编号
    content_en TEXT,                -- 内容（英文）
    content_zh TEXT,                -- 内容（中文）
    display_order INT,
    created_at TIMESTAMP,
    
    FOREIGN KEY (exercise_id) REFERENCES exercises(id)
);
```

## 🔍 筛选维度

### 1. 肌肉群（Muscles）
```
胸部 (Chest)、背部 (Back)、肩部 (Shoulders)
手臂 (Arms)、腿部 (Legs)、核心 (Core)
臀部 (Glutes)、小腿 (Calves)
```

### 2. 器械（Equipment）
```
杠铃 (Barbell)、哑铃 (Dumbbell)、固定器械 (Machine)
徒手 (Bodyweight)、拉力器 (Cable)、壶铃 (Kettlebell)
弹力带 (Resistance Band)
```

### 3. 难度（Difficulty）
```
新手 (Beginner)、中级 (Intermediate)、高级 (Advanced)
```

### 4. 力量类型（Force Type）
```
推 (Push)、拉 (Pull)、保持 (Hold)
```

### 5. 机制类型（Mechanic Type）
```
复合 (Compound) - 多关节参与
孤立 (Isolation) - 单关节参与
```

## 🚀 性能优化

### 1. 缓存策略
```php
// ExerciseCacheService.php
public function cacheFilterOptions(): void
{
    Cache::remember('exercise_filter_options', 3600, function () {
        return $this->exerciseFilterService->getFilterOptions();
    });
}

// 缓存热门动作
Cache::remember('popular_exercises', 1800, function () {
    return Exercise::orderBy('view_count', 'desc')->take(10)->get();
});
```

### 2. 数据库索引
```sql
-- 为常用筛选字段添加索引
CREATE INDEX idx_primary_muscles ON exercises(primary_muscles);
CREATE INDEX idx_equipment ON exercises(equipment);
CREATE INDEX idx_difficulty ON exercises(difficulty);
CREATE INDEX idx_view_count ON exercises(view_count);

-- 全文搜索索引
CREATE FULLTEXT INDEX idx_search ON exercises(name, name_zh, description, description_zh);
```

// 预加载媒体和指导步骤
