**版本**: v1.0.0  
**更新日期**: 2025-11-01

## 📋 概述

Infrastructure基础设施层提供了项目的基础组件和工具类，所有业务模块都依赖这一层。

### 核心职责

```
✅ 统一响应格式 - ApiResponse
✅ 基础控制器 - BaseController
✅ 基础仓储 - BaseRepository
✅ 中间件管理 - Middleware
✅ 辅助工具 - Helpers & Traits
```

---

## 🏗️ Infrastructure架构

### 目录结构

```
app/Infrastructure/
├── Http/                          # HTTP层基础设施
│   ├── Controllers/
│   │   └── BaseController.php     # 基础控制器
│   ├── Middleware/
│   │   └── InternalApiAuth.php    # 内部API认证
│   └── Responses/
│       └── ApiResponse.php        # 统一响应格式
│
└── Database/                      # 数据库层基础设施
    └── Repositories/
        └── BaseRepository.php     # 基础仓储
```

## 📦 核心组件

### 1. ApiResponse - 统一响应格式

#### 位置
```php
app/Infrastructure/Http/Responses/ApiResponse.php
```

#### 状态码常量

```php
// 成功状态
const SUCCESS = 200;              // 操作成功
const WARN = 601;                 // 警告

// 客户端错误 (4xx)
const BAD_REQUEST = 400;          // 请求参数错误
const UNAUTHORIZED = 401;         // 未认证
const FORBIDDEN = 403;            // 无权限
const NOT_FOUND = 404;            // 资源不存在
const UNPROCESSABLE_ENTITY = 422; // 验证失败
const TOO_MANY_REQUESTS = 429;    // 请求过于频繁

// 服务器错误 (5xx)
const INTERNAL_SERVER_ERROR = 500;// 服务器内部错误
const SERVICE_UNAVAILABLE = 503;  // 服务不可用
```

#### 核心方法

##### 1. 成功响应

```php
// 基础成功响应
ApiResponse::ok($data, '操作成功', 200)

// 示例
return ApiResponse::ok([
    'user' => $user,
    'token' => $token
], '登录成功');

// 响应格式
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "user": {...},
    "token": "..."
  }
}
```

##### 2. 失败响应

```php
// 基础失败响应
ApiResponse::fail('操作失败', 500, $data, $httpCode)

// 示例
return ApiResponse::fail('用户不存在', 404);

// 响应格式
{
  "code": 404,
  "msg": "用户不存在",
  "data": null
}
```

##### 3. 分页响应

```php
// 分页响应
ApiResponse::page($data, '查询成功')

// 示例
return ApiResponse::page([
    'rows' => $exercises,
    'total' => 1603,
    'page' => 1,
    'per_page' => 20,
    'total_pages' => 81
], '获取成功');

// 响应格式
{
  "code": 200,
  "msg": "获取成功",
  "data": {
    "rows": [...],
    "total": 1603,
    "page": 1,
    "per_page": 20,
    "total_pages": 81
  }
}
```

##### 4. 验证错误响应

```php
// 验证错误
ApiResponse::validationError('参数验证失败', $errors)

// 示例
return ApiResponse::validationError('参数验证失败', [
    'email' => ['邮箱格式不正确'],
    'password' => ['密码长度不能少于6位']
]);

// 响应格式
{
  "code": 422,
  "msg": "参数验证失败",
  "data": null,
  "errors": {
    "email": ["邮箱格式不正确"],
    "password": ["密码长度不能少于6位"]
  }
}
```

##### 5. 快捷错误响应

```php
// 404 - 资源不存在
ApiResponse::notFound('资源不存在')

// 401 - 未认证
ApiResponse::unauthorized('请先登录')

// 403 - 权限不足
ApiResponse::forbidden('权限不足')

// 429 - 请求过于频繁
ApiResponse::tooManyRequests('请求过于频繁，请稍后重试')

// 通用错误
ApiResponse::error('操作失败', 500)
```

#### 使用示例

```php
// 在Controller中使用（推荐继承BaseController）
class ExerciseController extends BaseController
{
    public function index()
    {
        $exercises = $this->service->getList();
        return $this->success($exercises, '获取成功');
    }
    
    public function show($id)
    {
        $exercise = $this->service->getDetail($id);
        
        if (!$exercise) {
            return $this->fail('动作不存在', 404);
        }
        
        return $this->success($exercise);
    }
}

// 直接使用ApiResponse
class UserController
{
    public function login(Request $request)
    {
        try {
            $result = $this->authService->login($request->all());
            return ApiResponse::ok($result, '登录成功');
        } catch (\Exception $e) {
            return ApiResponse::fail('登录失败: ' . $e->getMessage(), 401);
        }
    }
}
```

### 2. BaseController - 基础控制器

#### 位置
```php
app/Infrastructure/Http/Controllers/BaseController.php
```

#### 核心方法

##### 1. 统一成功响应

```php
protected function success($data = null, string $msg = '操作成功', int $httpCode = 200)

// 使用示例
return $this->success($user, '创建成功', 201);
```

##### 2. 统一失败响应

```php
protected function fail(string $msg = '操作失败', int $code = 500, $data = null, int $httpCode = null)

// 使用示例
return $this->fail('用户不存在', 404);
```

##### 3. 统一分页响应

```php
protected function page($rows, int $total, int $page = 1, int $perPage = 20, string $msg = '查询成功')

// 使用示例
return $this->page(
    $exercises,      // 数据行
    1603,           // 总数
    1,              // 当前页
    20,             // 每页数量
    '获取成功'
);
```

##### 4. 统一异常处理

```php
protected function handleException(\Exception $e, string $operation = 'unknown')

// 使用示例
public function create(Request $request)
{
    try {
        $result = $this->service->create($request->all());
        return $this->success($result, '创建成功', 201);
    } catch (\Exception $e) {
        return $this->handleException($e, '创建动作');
    }
}

// 自动处理不同类型的异常:
// - ValidationException → 422 验证错误
// - ModelNotFoundException → 404 资源不存在
// - AuthenticationException → 401 未认证
// - AuthorizationException → 403 权限不足
// - QueryException → 500 数据库错误
// - TooManyRequestsHttpException → 429 请求过于频繁
```

##### 5. 请求验证

```php
protected function validateRequest(Request $request, array $rules, array $messages = [])

// 使用示例
public function store(Request $request)
{
    $validated = $this->validateRequest($request, [
        'name' => 'required|string|max:255',
        'email' => 'required|email|unique:users',
        'password' => 'required|min:6|confirmed'
    ]);
    
    // 使用验证后的数据
    $user = $this->service->create($validated);
    return $this->success($user, '创建成功', 201);
}
```

##### 6. API调用日志

```php
protected function logApiCall(string $action, array $data = [])

// 使用示例
public function purchase(Request $request)
{
    $this->logApiCall('purchase_membership', [
        'membership_id' => $request->membership_id,
        'amount' => $request->amount
    ]);
    
    // 执行购买逻辑
    ...
}

// 日志内容包含:
// - request_id (请求ID)
// - user_id (用户ID)
// - ip_address (IP地址)
// - user_agent (User Agent)
// - method (HTTP方法)
// - url (完整URL)
// - 自定义数据
```

#### 使用示例

```php
namespace App\Modules\Exercise\Controllers;

use App\Infrastructure\Http\Controllers\BaseController;
use App\Modules\Exercise\Services\ExerciseService;
use Illuminate\Http\Request;

class ExerciseController extends BaseController
{
    protected ExerciseService $service;
    
    public function __construct(ExerciseService $service)
    {
        $this->service = $service;
    }
    
    // 使用 success() 方法
    public function index(Request $request)
    {
        $exercises = $this->service->getList($request->all());
        return $this->success($exercises, '获取成功');
    }
    
    // 使用 fail() 方法
    public function show($id)
    {
        $exercise = $this->service->getDetail($id);
        
        if (!$exercise) {
            return $this->fail('动作不存在', 404);
        }
        
        return $this->success($exercise);
    }
    
    // 使用 handleException() 方法
    public function store(Request $request)
    {
        try {
            $exercise = $this->service->create($request->all());
            return $this->success($exercise, '创建成功', 201);
        } catch (\Exception $e) {
            return $this->handleException($e, '创建动作');
        }
    }
    
    // 使用 page() 方法
    public function paginate(Request $request)
    {
        $result = $this->service->getPaginated($request->all());
        
        return $this->page(
            $result['rows'],
            $result['total'],
            $result['page'],
            $result['per_page'],
            '获取成功'
        );
    }
}
```

### 3. BaseRepository - 基础仓储

#### 位置
```php
app/Infrastructure/Database/Repositories/BaseRepository.php
```

#### 核心方法

##### 1. 查找所有记录

```php
public function all(array $columns = ['*']): array

// 使用示例
$allExercises = $this->repository->all();
$selectedColumns = $this->repository->all(['id', 'name', 'difficulty']);
```

##### 2. 根据条件查找

```php
public function findWhere(array $where, array $columns = ['*']): array

// 使用示例
// 简单条件
$beginnerExercises = $this->repository->findWhere([
    'difficulty' => 'beginner'
]);

// 复杂条件
$exercises = $this->repository->findWhere([
    'difficulty' => 'beginner',
    ['view_count', '>', 100]
]);
```

##### 3. 创建记录

```php
public function create(array $data): array

// 使用示例
$exercise = $this->repository->create([
    'name' => 'Push Up',
    'difficulty' => 'beginner',
    'equipment' => 'body_only'
]);
```

##### 4. 更新记录

```php
public function update(int $id, array $data): bool

// 使用示例
$updated = $this->repository->update($exerciseId, [
    'name' => 'Updated Name',
    'difficulty' => 'intermediate'
]);
```

##### 5. 删除记录

```php
public function delete(int $id): bool

// 使用示例
$deleted = $this->repository->delete($exerciseId);
```

##### 6. 批量插入

```php
public function bulkInsert(array $data): bool

// 使用示例
$inserted = $this->repository->bulkInsert([
    ['name' => 'Exercise 1', 'difficulty' => 'beginner'],
    ['name' => 'Exercise 2', 'difficulty' => 'intermediate'],
    ['name' => 'Exercise 3', 'difficulty' => 'advanced']
]);
```

#### 使用示例

```php
namespace App\Modules\Exercise\Repositories;

use App\Infrastructure\Database\Repositories\BaseRepository;
use App\Modules\Exercise\Models\Exercise;

class ExerciseRepository extends BaseRepository
{
    protected $model = Exercise::class;
    
    // 继承BaseRepository的所有方法
    
    // 添加自定义方法
    public function findBySlug(string $slug): ?array
    {
        $exercise = $this->getModel()
            ->where('slug', $slug)
            ->first();
            
        return $exercise ? $exercise->toArray() : null;
    }
    
    // 使用继承的方法
    public function createExercise(array $data): array
    {
        // 使用基类的 create() 方法
        return $this->create($data);
    }
}
```

```php
INTERNAL_API_TOKEN=your-secret-token

```

## 💡 最佳实践

### 1. Controller继承BaseController

```php
✅ 正确做法:
class ExerciseController extends BaseController
{
    public function index()
    {
        return $this->success($data);  // 使用继承的方法
    }
}

❌ 错误做法:
class ExerciseController extends Controller  // ❌ 不继承BaseController
{
    public function index()
    {
        return response()->json([...]);  // ❌ 手动构建响应
    }
}
```

---

### 2. Repository继承BaseRepository

```php
✅ 正确做法:
class UserRepository extends BaseRepository implements UserRepositoryInterface
{
    protected $model = User::class;
    
    // 使用继承的方法 + 添加自定义方法
}

❌ 错误做法:
class UserRepository  // ❌ 不继承BaseRepository
{
    // 自己实现所有CRUD方法
}
```

---

### 3. 统一响应格式

```php
✅ 所有API响应都使用ApiResponse:

// Controller中
return $this->success($data);
return $this->fail('错误信息', 404);

// 或直接使用
return ApiResponse::ok($data);
return ApiResponse::fail('错误信息');

❌ 不要手动构建响应:
return response()->json(['status' => 'ok', 'data' => $data]);  // ❌
```

---

### 4. 异常处理

```php
✅ 使用BaseController的handleException:
public function store(Request $request)
{
    try {
        $result = $this->service->create($request->all());
        return $this->success($result, '创建成功', 201);
    } catch (\Exception $e) {
        return $this->handleException($e, '创建资源');
    }
}

// 或者抛出异常，让全局异常处理器处理
public function store(Request $request)
{
    $result = $this->service->create($request->all());
    return $this->success($result, '创建成功', 201);
    // 如果抛出异常，全局异常处理器会自动处理
}
```

## 🎯 常见场景

### 场景1: CRUD操作

```php
class ResourceController extends BaseController
{
    // 列表
    public function index()
    {
        $data = $this->service->getList();
        return $this->success($data);
    }
    
    // 详情
    public function show($id)
    {
        $data = $this->service->getDetail($id);
        return $this->success($data);
    }
    
    // 创建
    public function store(Request $request)
    {
        $data = $this->service->create($request->all());
        return $this->success($data, '创建成功', 201);
    }
    
    // 更新
    public function update($id, Request $request)
    {
        $data = $this->service->update($id, $request->all());
        return $this->success($data, '更新成功');
    }
    
    // 删除
    public function destroy($id)
    {
        $this->service->delete($id);
        return $this->success(null, '删除成功');
    }
}
```
