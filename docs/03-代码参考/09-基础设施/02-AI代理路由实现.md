## 概述

### 什么是AI代理路由

AI代理路由是PHP后端提供的一个HTTP代理层，负责将前端的AI聊天请求转发到DAML-RAG服务，并将响应返回给前端。

### 为什么需要代理

1. **统一入口**: 前端只需要访问一个域名（api.yuzhen-fitness.cn），无需直接访问AI服务
2. **安全隔离**: DAML-RAG服务可以部署在内网，不直接暴露给公网
3. **CORS处理**: 由后端统一处理跨域问题，前端无需关心
4. **请求增强**: 可以在代理层添加认证、日志、限流等功能
5. **灵活切换**: 可以轻松切换AI服务提供商，前端无需修改

### 核心功能

- ✅ 流式聊天请求代理（SSE）
- ✅ 非流式聊天请求代理
- ✅ 健康检查代理
- ✅ 请求日志记录
- ✅ 错误处理和降级

## 架构设计

### 请求流程

```
前端PWA (app.yuzhen-fitness.cn)
    ↓
    POST /api/ai/v1/chat/stream
    ↓
PHP后端 (api.yuzhen-fitness.cn)
    ↓ AiProxyController
    ↓ 转发请求
    ↓
DAML-RAG服务 (fitness_daml_rag:8001)
    ↓ /api/v1/chat/stream
    ↓ 处理AI请求
    ↓
    返回SSE流式响应
    ↓
PHP后端 (流式转发)
    ↓
前端PWA (接收SSE事件)
```

### 三端协作

| 端 | 职责 | 技术栈 |
|---|------|--------|
| **前端PWA** | 用户界面、发起请求 | Vue 3 + TypeScript |
| **PHP后端** | 请求代理、认证授权 | Laravel 11 |
| **DAML-RAG** | AI推理、知识检索 | Python + FastAPI |

## 路由配置

### 路由定义位置

**文件**: `routes/api.php`

### 路由代码

```php
/*
|--------------------------------------------------------------------------
| AI代理路由（直接在api.php中定义，避免CORS问题）
|--------------------------------------------------------------------------
| 前端请求: /api/ai/v1/chat/stream
| 代理到: DAML-RAG服务
| 
| 注意：使用api中间件组，自动处理CORS，无需CSRF验证
*/
Route::prefix('ai')->group(function () {
    // 流式聊天接口
    Route::post('/v1/chat/stream', [\App\Http\Controllers\AiProxyController::class, 'streamChat']);
    
    // 非流式聊天接口
    Route::post('/v1/chat', [\App\Http\Controllers\AiProxyController::class, 'chat']);
    
    // 健康检查
    Route::get('/health', [\App\Http\Controllers\AiProxyController::class, 'health']);
});
```

### 路由特点

1. **路径前缀**: `/api/ai/*`
2. **中间件组**: `api`（自动应用CORS、限流等）
3. **无CSRF验证**: 通过VerifyCsrfToken中间件排除
4. **RESTful设计**: 遵循HTTP方法语义

| **本地开发** | http://localhost:8000 | http://localhost:8000/api/ai/v1/chat/stream |
| **生产环境** | https://api.yuzhen-fitness.cn | https://api.yuzhen-fitness.cn/api/ai/v1/chat/stream |

### 核心方法

#### 1. streamChat() - 流式聊天

**功能**: 代理流式聊天请求，使用SSE（Server-Sent Events）协议

**实现要点**:
- 使用cURL进行流式请求（Laravel Http不支持流式响应）
- 返回StreamedResponse
- 实时转发数据块
- 设置正确的响应头

**代码示例**:

```php
public function streamChat(Request $request): StreamedResponse
{
    $data = $request->all();
    
    Log::info('[AiProxy] 流式聊天请求', [
        'user_id' => $data['user_id'] ?? null,
        'query' => substr($data['query'] ?? '', 0, 100),
        'strategy' => $data['strategy'] ?? 'dag'
    ]);
    
    return new StreamedResponse(function () use ($data) {
        $url = "{$this->damlRagUrl}/api/v1/chat/stream";
        
        try {
            // 使用cURL进行流式请求
            $ch = curl_init();
            
            curl_setopt_array($ch, [
                CURLOPT_URL => $url,
                CURLOPT_POST => true,
                CURLOPT_POSTFIELDS => json_encode($data),
                CURLOPT_HTTPHEADER => [
                    'Content-Type: application/json',
                    'Accept: text/event-stream',
                ],
                CURLOPT_RETURNTRANSFER => false,
                CURLOPT_WRITEFUNCTION => function ($ch, $chunk) {
                    echo $chunk;
                    ob_flush();
                    flush();
                    return strlen($chunk);
                },
                CURLOPT_TIMEOUT => 300, // 5分钟超时
                CURLOPT_CONNECTTIMEOUT => 30,
            ]);
            
            $result = curl_exec($ch);
            
            if (curl_errno($ch)) {
                $error = curl_error($ch);
                Log::error('[AiProxy] cURL错误', ['error' => $error]);
                echo "data: " . json_encode([
                    'type' => 'error',
                    'error' => "连接AI服务失败: {$error}"
                ]) . "\n\n";
            }
            
            curl_close($ch);
            
        } catch (\Exception $e) {
            Log::error('[AiProxy] 流式请求异常', [
                'error' => $e->getMessage(),
                'trace' => $e->getTraceAsString()
            ]);
            
            echo "data: " . json_encode([
                'type' => 'error',
                'error' => "AI服务异常: {$e->getMessage()}"
            ]) . "\n\n";
        }
    }, 200, [
        'Content-Type' => 'text/event-stream',
        'Cache-Control' => 'no-cache',
        'Connection' => 'keep-alive',
        'X-Accel-Buffering' => 'no', // 禁用nginx缓冲
        'Access-Control-Allow-Origin' => '*',
        'Access-Control-Allow-Methods' => 'POST, OPTIONS',
        'Access-Control-Allow-Headers' => 'Content-Type, Authorization',
    ]);
}
```

**关键配置**:
- `CURLOPT_WRITEFUNCTION`: 自定义写入函数，实时输出数据块
- `ob_flush()` + `flush()`: 强制刷新输出缓冲区
- `X-Accel-Buffering: no`: 禁用nginx缓冲（生产环境必需）

#### 2. chat() - 非流式聊天

**功能**: 代理非流式聊天请求，返回完整JSON响应

**实现要点**:
- 使用Laravel Http客户端
- 设置120秒超时
- 统一错误处理

**代码示例**:

```php
public function chat(Request $request)
{
    $data = $request->all();
    
    Log::info('[AiProxy] 非流式聊天请求', [
        'user_id' => $data['user_id'] ?? null,
        'query' => substr($data['query'] ?? '', 0, 100)
    ]);
    
    try {
        $response = Http::timeout(120)
            ->post("{$this->damlRagUrl}/api/v1/chat", $data);
        
        if ($response->successful()) {
            return response()->json($response->json());
        }
        
        Log::error('[AiProxy] DAML-RAG响应错误', [
            'status' => $response->status(),
            'body' => $response->body()
        ]);
        
        return response()->json([
            'code' => $response->status(),
            'msg' => 'AI服务响应错误',
            'data' => null
        ], $response->status());
        
    } catch (\Exception $e) {
        Log::error('[AiProxy] 非流式请求异常', [
            'error' => $e->getMessage()
        ]);
        
        return response()->json([
            'code' => 500,
            'msg' => "AI服务异常: {$e->getMessage()}",
            'data' => null
        ], 500);
    }
}
```

#### 3. health() - 健康检查

**功能**: 检查DAML-RAG服务是否可用

public function health()

            'data' => null
        ], 500);
    }
}

## CSRF验证排除

### 为什么需要排除

1. **API性质**: AI代理路由是纯API接口，不涉及表单提交
2. **跨域请求**: 前端PWA与后端API是不同域名，无法共享CSRF token
3. **认证方式**: 使用JWT token进行认证，不依赖session

### 配置方法

**文件**: `app/Http/Middleware/VerifyCsrfToken.php`

```php
<?php

namespace App\Http\Middleware;

use Illuminate\Foundation\Http\Middleware\VerifyCsrfToken as Middleware;

class VerifyCsrfToken extends Middleware
{
    /**
     * The URIs that should be excluded from CSRF verification.
     *
     * @var array<int, string>
     */
    protected $except = [
        'ai/*',  // AI代理路由，前端通过API调用，不需要CSRF验证
    ];
}
```

### 安全考虑

虽然排除了CSRF验证，但安全性仍然得到保障：

1. **CORS限制**: 只允许特定域名访问
2. **JWT认证**: 可以添加JWT中间件进行用户认证
3. **限流保护**: 可以添加throttle中间件防止滥用
4. **日志记录**: 所有请求都会记录日志，便于审计

## CORS跨域处理

### 问题背景

前端PWA（app.yuzhen-fitness.cn）需要访问后端API（api.yuzhen-fitness.cn），涉及跨域请求。

### 历史问题

**问题**: 最初将AI代理路由放在`routes/web.php`中，导致CORS配置不生效

**原因**: `web`中间件组不包含CORS处理，需要手动配置

### 解决方案

**方案**: 将AI代理路由移至`routes/api.php`

**优势**:
- `api`中间件组自动应用CORS配置
- 无需额外配置
- 与其他API路由保持一致

### CORS配置

**文件**: `config/cors.php`

```php
<?php

return [
    'paths' => ['api/*', 'ai/*', 'sanctum/csrf-cookie'],

    'allowed_methods' => ['*'],

    'allowed_origins' => [
        'https://app.yuzhen-fitness.cn',
        'https://yuzhen-fitness.cn',
        'https://www.yuzhen-fitness.cn',
        'http://localhost:9000', // 本地开发
    ],

    'allowed_origins_patterns' => [],

    'allowed_headers' => ['*'],

    'exposed_headers' => [],

    'max_age' => 0,

    'supports_credentials' => true,
];
```

### 中间件配置

**文件**: `app/Http/Kernel.php`

```php
protected $middlewareGroups = [
    'api' => [
        \Illuminate\Routing\Middleware\SubstituteBindings::class,
        // CORS由config/cors.php配置，自动应用
    ],
];
```

### 响应头设置

在`streamChat()`方法中，手动设置CORS响应头（作为备用）：

```php
return new StreamedResponse(function () use ($data) {
    // ... 流式处理逻辑
}, 200, [
    'Content-Type' => 'text/event-stream',
    'Cache-Control' => 'no-cache',
    'Connection' => 'keep-alive',
    'X-Accel-Buffering' => 'no',
    'Access-Control-Allow-Origin' => '*',  // CORS头
    'Access-Control-Allow-Methods' => 'POST, OPTIONS',
    'Access-Control-Allow-Headers' => 'Content-Type, Authorization',
]);
```

## 使用示例

### 前端调用示例

#### 流式聊天（推荐）

```typescript
// 使用EventSource接收SSE流
const eventSource = new EventSource(
  'https://api.yuzhen-fitness.cn/api/ai/v1/chat/stream',
  {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    },
    body: JSON.stringify({
      user_id: 'user_123',
      query: '如何练胸肌？',
      strategy: 'dag',
      session_id: 'session_456',
      topic_id: 1
    })
  }
);

eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  
  if (data.type === 'chunk') {
    // 追加内容到UI
    appendToChat(data.content);
  } else if (data.type === 'end') {
    // 关闭连接
    eventSource.close();
  }
};

eventSource.onerror = (error) => {
  console.error('SSE错误:', error);
  eventSource.close();
};
```

## 故障排查

### 常见问题

#### 1. CORS错误

**症状**:
```
Access to fetch at 'https://api.yuzhen-fitness.cn/api/ai/v1/chat/stream' 
from origin 'https://app.yuzhen-fitness.cn' has been blocked by CORS policy
```

**排查步骤**:
1. 检查`config/cors.php`中是否包含前端域名
2. 确认路由在`routes/api.php`中（不是web.php）
3. 检查nginx配置是否重复添加CORS头

**解决方案**:
```php
// config/cors.php
'allowed_origins' => [
    'https://app.yuzhen-fitness.cn',  // 确保包含前端域名
    'http://localhost:9000',
],
```

#### 2. 连接超时

**症状**:
```
AI服务连接失败: Operation timed out after 30000 milliseconds
```

**排查步骤**:
1. 检查DAML-RAG服务是否运行
2. 检查网络连接
3. 检查环境变量`DAML_RAG_URL`是否正确

**解决方案**:
```bash
# 检查服务状态
docker ps | grep fitness_daml_rag

# 检查网络连接
docker exec fitness_php_v2 ping fitness_daml_rag

# 检查环境变量
docker exec fitness_php_v2 env | grep DAML_RAG_URL
```

#### 3. 流式响应被缓冲

**症状**: 流式响应不是实时返回，而是等待全部完成后一次性返回

**原因**: nginx或PHP缓冲了输出

**解决方案**:

**PHP配置**:
```php
// 在streamChat()方法中
ob_flush();
flush();
```

**nginx配置**:
```nginx
location /api/ai/ {
    proxy_buffering off;  # 禁用缓冲
    proxy_cache off;
    proxy_read_timeout 300s;
}
```

**响应头**:
```php
'X-Accel-Buffering' => 'no',  // 禁用nginx缓冲
```

#### 4. CSRF验证失败

**症状**:
```
419 | Page Expired
```

**排查步骤**:
1. 检查`app/Http/Middleware/VerifyCsrfToken.php`
2. 确认`ai/*`在排除列表中

**解决方案**:
```php
// app/Http/Middleware/VerifyCsrfToken.php
protected $except = [
    'ai/*',  // 确保包含此行
];
```

**PHP后端日志**:

# 生产环境（Zeabur）
