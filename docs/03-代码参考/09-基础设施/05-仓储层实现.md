## 📋 概述

Repositories仓储层是数据访问层的核心，负责封装所有数据库操作，为Service层提供简洁的数据访问接口。

### 设计原则

```
✅ 单一职责 - 每个Repository只负责一个数据实体
✅ 接口导向 - 定义接口，面向接口编程
✅ 数据封装 - 隐藏查询细节，返回数组/集合
✅ 可测试性 - 易于Mock，便于单元测试
✅ 无业务逻辑 - 只做数据CRUD，不包含业务逻辑
```

## 🏗️ Repositories架构

### 目录结构

```
app/Modules/{Module}/Repositories/
├── Interfaces/
│   └── {Module}RepositoryInterface.php  # 接口定义
└── {Module}Repository.php               # 具体实现

继承关系:
{Module}Repository extends BaseRepository implements {Module}RepositoryInterface
```

## 📦 BaseRepository

### 位置与职责

```php
位置: app/Infrastructure/Database/Repositories/BaseRepository.php

职责:
- 提供通用CRUD方法
- 统一返回格式（数组）
- 查询构建器封装

通用方法:
- find($id)              // 根据ID查找
- findOrFail($id)        // 查找或抛出异常
- all()                  // 获取所有记录
- paginate($perPage)     // 分页查询
- create($data)          // 创建记录
- update($id, $data)     // 更新记录
- delete($id)            // 删除记录
- exists($id)            // 检查是否存在
```

## 💡 Repository开发最佳实践

### 1. 标准Repository结构

```php
<?php

namespace App\Modules\{Module}\Repositories;

use App\Modules\{Module}\Repositories\Interfaces\{Module}RepositoryInterface;
use App\Modules\{Module}\Models\{Model};
use App\Infrastructure\Database\Repositories\BaseRepository;

/**
 * {Module} Repository
 * 
 * {模块}数据访问层实现
 * 
 * @version 1.0.0
 * @date 2025-11-01
 */
class {Module}Repository extends BaseRepository implements {Module}RepositoryInterface
{
    protected $model = {Model}::class;

    /**
     * 根据ID查找
     */
    public function findById(int $id): ?array
    {
        $result = {Model}::find($id);
        return $result ? $result->toArray() : null;
    }

    /**
     * 根据条件查找
     */
    public function findByConditions(array $conditions): array
    {
        $query = {Model}::query();
        
        foreach ($conditions as $field => $value) {
            $query->where($field, $value);
        }
        
        return $query->get()->toArray();
    }

    /**
     * 分页查询
     */
    public function paginate(array $filters, int $page, int $perPage): array
    {
        $query = {Model}::query();
        
        // 应用筛选
        $this->applyFilters($query, $filters);
        
        $paginator = $query->paginate($perPage, ['*'], 'page', $page);
        
        return [
            'rows' => $paginator->items(),
            'total' => $paginator->total(),
            'page' => $paginator->currentPage(),
            'per_page' => $paginator->perPage(),
            'total_pages' => $paginator->lastPage(),
        ];
    }

    /**
     * 创建记录
     */
    public function create(array $data): array
    {
        $model = {Model}::create($data);
        return $model->toArray();
    }

    /**
     * 更新记录
     */
    public function update(int $id, array $data): array
    {
        $model = {Model}::findOrFail($id);
        $model->update($data);
        return $model->fresh()->toArray();
    }

    /**
     * 删除记录
     */
    public function delete(int $id): bool
    {
        return {Model}::destroy($id) > 0;
    }

    /**
     * 私有方法：应用筛选条件
     */
    private function applyFilters($query, array $filters): void
    {
        // 实现筛选逻辑
    }
}
```

### 3. 返回格式规范

```php
✅ 正确做法 - 返回数组:
public function findById(int $id): ?array
{
    $model = Exercise::find($id);
    return $model ? $model->toArray() : null;
}

❌ 错误做法 - 返回Model实例:
public function findById(int $id): ?Exercise
{
    return Exercise::find($id);  // ❌ 不要返回Model
}

原因:
- 返回数组更灵活，易于序列化
- Service层不直接依赖Model
- 易于测试和Mock
```

---

### 4. Eager Loading优化

```php
✅ 使用Eager Loading避免N+1问题:
public function findById(int $id): ?array
{
    $exercise = Exercise::with([
        'media',
        'instructions',
        'secondaryMuscles',
        'tags'
    ])->find($id);
    
    return $exercise ? $exercise->toArray() : null;
}

// 1次主查询 + 4次关联查询 = 5次查询
// 而不是 1 + N*4 次查询
```

## 📊 Repository vs Service

| 维度 | Repository | Service |
|------|-----------|---------|
| **职责** | 数据访问 | 业务逻辑 |
| **返回值** | 数组/集合 | 数组/对象 |
| **查询** | 简单查询 | 复杂业务查询 |
| **事务** | 不管理 | 管理事务 |
| **缓存** | 不管理 | 管理缓存 |
| **事件** | 不触发 | 触发事件 |
| **验证** | 不验证 | 验证业务规则 |

## 🧪 Repository测试

### 单元测试示例

```php
use Tests\TestCase;
use App\Modules\Exercise\Repositories\ExerciseRepository;
use App\Modules\Exercise\Models\Exercise;
use Illuminate\Foundation\Testing\RefreshDatabase;

class ExerciseRepositoryTest extends TestCase
{
    use RefreshDatabase;
    
    protected ExerciseRepository $repository;
    
    protected function setUp(): void
    {
        parent::setUp();
        $this->repository = new ExerciseRepository();
    }
    
    public function test_find_by_id_returns_exercise()
    {
        // 1. 准备数据
        $exercise = Exercise::factory()->create([
            'name' => 'Push Up',
            'difficulty' => 'beginner'
        ]);
        
        // 2. 调用Repository
        $result = $this->repository->findById($exercise->id);
        
        // 3. 断言
        $this->assertNotNull($result);
        $this->assertEquals('Push Up', $result['name']);
        $this->assertEquals('beginner', $result['difficulty']);
    }
    
    public function test_paginate_returns_correct_structure()
    {
        // 创建测试数据
        Exercise::factory()->count(50)->create();
        
        // 调用分页
        $result = $this->repository->paginate([], 1, 20);
        
        // 断言
        $this->assertArrayHasKey('rows', $result);
        $this->assertArrayHasKey('total', $result);
        $this->assertArrayHasKey('page', $result);
        $this->assertCount(20, $result['rows']);
        $this->assertEquals(50, $result['total']);
    }
}
```

// Repository方法
public function findWithFilters(array $filters): array
{
    $query = Exercise::query();
    
    if (!empty($filters['muscle'])) {
        $query->where('primary_muscles', 'like', "%{$filters['muscle']}%");
    }
    
    if (!empty($filters['equipment'])) {
        $query->where('equipment', $filters['equipment']);
    }

        $query->where('difficulty', $filters['difficulty']);
    }
    
    return $query->get()->toArray();
}
