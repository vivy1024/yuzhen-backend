## 📋 概述

Services服务层是业务逻辑的核心，负责处理复杂的业务规则、编排多个Repository、处理事务和缓存等。

### 设计原则

```
✅ 单一职责 - 每个Service专注一个业务领域
✅ 依赖注入 - 通过构造函数注入依赖
✅ 接口导向 - 依赖Repository接口而非实现
✅ 无状态 - Service不应保存状态
✅ 可测试 - 易于Mock和单元测试
```

## 💡 Service开发最佳实践

### 1. 标准Service结构

```php
<?php

namespace App\Modules\{Module}\Services;

use App\Modules\{Module}\Repositories\Interfaces\{Module}RepositoryInterface;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\DB;

/**
 * {Module} Service
 * 
 * {模块}核心业务逻辑
 * 
 * @version 1.0.0
 * @date 2025-11-01
 */
class {Module}Service
{
    protected {Module}RepositoryInterface $repository;
    
    public function __construct(
        {Module}RepositoryInterface $repository
    ) {
        $this->repository = $repository;
    }

    /**
     * 业务方法示例
     */
    public function doSomething(int $id, array $data): array
    {
        // 1. 参数验证
        $this->validateData($data);
        
        // 2. 业务逻辑
        DB::beginTransaction();
        try {
            $result = $this->repository->update($id, $data);
            
            // 3. 触发事件
            event(new SomethingHappened($result));
            
            DB::commit();
            return $result;
        } catch (\Exception $e) {
            DB::rollBack();
            throw $e;
        }
    }
    
    /**
     * 私有方法：数据验证
     */
    private function validateData(array $data): void
    {
        // 验证逻辑
    }
}
```

---

### 2. 使用依赖注入

```php
✅ 正确做法 - 构造函数注入:
public function __construct(
    ExerciseRepositoryInterface $exerciseRepo,
    ExerciseCacheService $cacheService
) {
    $this->exerciseRepo = $exerciseRepo;
    $this->cacheService = $cacheService;
}

❌ 错误做法 - 直接实例化:
public function doSomething() {
    $repo = new ExerciseRepository(); // ❌ 不要这样
}
```

---

### 3. 事务处理

```php
✅ 正确做法:
DB::beginTransaction();
try {
    $this->repository->create($data);
    $this->otherRepository->update($otherId, $otherData);
    
    DB::commit();
} catch (\Exception $e) {
    DB::rollBack();
    throw $e;
}

❌ 错误做法 - 没有事务:
$this->repository->create($data);
$this->otherRepository->update($otherId, $otherData); // 可能不一致
```

---

### 4. 缓存策略

```php
✅ 使用CacheService:
public function getList(array $filters): array
{
    $cacheKey = $this->cacheService->generateKey($filters);
    
    return Cache::remember($cacheKey, 3600, function () use ($filters) {
        return $this->repository->getList($filters);
    });
}

// 更新时失效缓存
public function update(int $id, array $data): array
{
    $result = $this->repository->update($id, $data);
    $this->cacheService->invalidate($id);
    return $result;
}
```

---

### 5. 事件触发

```php
use App\Modules\{Module}\Events\{Event};

public function create(array $data): array
{
    $result = $this->repository->create($data);
    
    // 触发事件
    event(new {Event}($result));
```

## 🔧 Service注册与使用

### 在ServiceProvider中注册

```php
// app/Modules/Exercise/Providers/ExerciseServiceProvider.php

public function register()
{
    // 绑定Repository接口
    $this->app->bind(
        ExerciseRepositoryInterface::class,
        ExerciseRepository::class
    );
    
    // 绑定Service（单例）
    $this->app->singleton(ExerciseService::class, function ($app) {
        return new ExerciseService(
            $app->make(ExerciseRepositoryInterface::class),
            $app->make(ExerciseCacheService::class)
        );
    });
}
```

---

### 在Controller中使用

```php
// 方式1: 构造函数注入（推荐）
class ExerciseController extends BaseController
{
    protected ExerciseService $exerciseService;
    
    public function __construct(ExerciseService $exerciseService)
    {
        $this->exerciseService = $exerciseService;
    }
    
    public function index(Request $request)
    {
        $exercises = $this->exerciseService->getList($request->all());
        return $this->success($exercises);
    }
}

// 方式2: 方法注入
public function show(int $id, ExerciseService $exerciseService)
{
    $exercise = $exerciseService->getDetail($id);
    return $this->success($exercise);
}

// 方式3: 使用app()辅助函数
public function index()
{
    $exerciseService = app(ExerciseService::class);
    $exercises = $exerciseService->getList([]);
    return $this->success($exercises);
}
```

## 📊 Service与Repository对比

| 维度 | Service | Repository |
|------|---------|-----------|
| **职责** | 业务逻辑 | 数据访问 |
| **复杂度** | 可以很复杂 | 应该简单 |
| **事务** | 管理事务 | 不管事务 |
| **缓存** | 管理缓存 | 不管缓存 |
| **事件** | 触发事件 | 不触发 |
| **调用关系** | 调用Repository | 调用Model |
| **测试** | Mock Repository | Mock Model |

## 🎯 常见场景

### 场景1: CRUD操作

```php
public function create(array $data): array
{
    // 1. 数据验证（可选，通常在Request中）
    $this->validate($data);
    
    // 2. 调用Repository
    $result = $this->repository->create($data);
    
    // 3. 触发事件
    event(new ResourceCreated($result));
    
    // 4. 清除相关缓存
    $this->cacheService->invalidateList();
    
    return $result;
}
```

---

### 场景2: 复杂查询

```php
public function getRecommendations(int $userId): array
{
    // 1. 获取用户档案
    $profile = $this->userRepository->getProfile($userId);
    
    // 2. 根据档案筛选
    $filters = $this->buildFiltersFromProfile($profile);
    
    // 3. 调用Repository查询
    $exercises = $this->exerciseRepository->findByFilters($filters);
    
    // 4. 应用推荐算法
    $recommendations = $this->applyRecommendationAlgorithm($exercises, $profile);
    
    return $recommendations;
}
```

---

### 场景3: 跨模块协作

```php
public function purchaseMembership(int $userId, int $membershipId): array
{
    DB::beginTransaction();
    try {
        // 1. 创建订单（Membership模块）
        $order = $this->orderRepository->create([
            'user_id' => $userId,
            'membership_id' => $membershipId,
        ]);
        
        // 2. 处理支付（Payment模块）
        $payment = $this->paymentService->process($order);
        
        // 3. 激活会员（Membership模块）
        $membership = $this->membershipRepository->activate($userId, $membershipId);
        
        // 4. 触发事件
        event(new MembershipPurchased($userId, $membershipId));
        
        DB::commit();
        return compact('order', 'payment', 'membership');
    } catch (\Exception $e) {
        DB::rollBack();
        throw $e;
    }
}
```

## 🧪 Service测试

### 单元测试示例

```php
use Tests\TestCase;
use App\Modules\Exercise\Services\ExerciseService;
use App\Modules\Exercise\Repositories\Interfaces\ExerciseRepositoryInterface;
use Mockery;

class ExerciseServiceTest extends TestCase
{
    public function test_get_list_returns_exercises()
    {
        // 1. Mock Repository
        $mockRepo = Mockery::mock(ExerciseRepositoryInterface::class);
        $mockRepo->shouldReceive('paginate')
            ->once()
            ->with(['muscle' => 'chest'], 1, 20)
            ->andReturn([
                'rows' => [['id' => 1, 'name' => 'Push Up']],
                'total' => 1,
            ]);
        
        // 2. 创建Service
        $service = new ExerciseService($mockRepo, app(ExerciseCacheService::class));
        
        // 3. 调用方法
        $result = $service->getList(['muscle' => 'chest'], 1, 20);
        
        // 4. 断言
        $this->assertCount(1, $result['rows']);
        $this->assertEquals('Push Up', $result['rows'][0]['name']);
    }
}
```
