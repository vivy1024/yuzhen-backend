### 2. SSL证书配置

**推荐方案**: 使用Let's Encrypt免费证书 + 自动续期

```bash
# 使用certbot自动申请
certbot certonly --webroot \
  -w /var/www/html \
  -d yuzhen-fitness.cn \
  -d www.yuzhen-fitness.cn \
  -d api.yuzhen-fitness.cn \
  --email your@email.com

# 自动续期
0 3 * * * certbot renew --quiet
```

**或使用阿里云SSL证书**:
- 免费版: 单域名，1年有效期
- 付费版: 通配符证书 `*.yuzhen-fitness.cn`

## 🚀 Nginx配置示例

> ⚠️ **使用宝塔面板？** 查看 [宝塔面板部署指南.md](./宝塔面板部署指南.md)

### 前端配置（yuzhen-fitness.cn）

```nginx
server {
    listen 80;
    server_name yuzhen-fitness.cn www.yuzhen-fitness.cn;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yuzhen-fitness.cn www.yuzhen-fitness.cn;
    
    ssl_certificate /etc/letsencrypt/live/yuzhen-fitness.cn/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yuzhen-fitness.cn/privkey.pem;
    
    root /var/www/yuzhen-frontend/dist/spa;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

---

### API配置（api.yuzhen-fitness.cn）

```nginx
server {
    listen 80;
    server_name api.yuzhen-fitness.cn;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.yuzhen-fitness.cn;
    
    ssl_certificate /etc/letsencrypt/live/api.yuzhen-fitness.cn/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.yuzhen-fitness.cn/privkey.pem;
    
    root /var/www/yuzhen-backend/public;
    index index.php;
    
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    
    location ~ \.php$ {
        fastcgi_pass php:9000;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }
    
    # CORS配置
    add_header Access-Control-Allow-Origin https://yuzhen-fitness.cn;
    add_header Access-Control-Allow-Methods "GET, POST, PUT, DELETE, OPTIONS";
    add_header Access-Control-Allow-Headers "Authorization, Content-Type";
}
```
