## 📋 部署步骤速查

### 1️⃣ 安装宝塔（5分钟）

```bash

# 保存登录信息！

```

### 3️⃣ 添加网站（2分钟）

**API后端**:
```
域名: api.yuzhen-fitness.cn
目录: /www/wwwroot/yuzhen-backend/public
PHP: PHP-82
数据库: 自动创建
```

**前端PWA**:
```
域名: yuzhen-fitness.cn
目录: /www/wwwroot/yuzhen-frontend
PHP: 纯静态
```

---

### 4️⃣ SSL证书（2分钟）

网站设置 → SSL → Let's Encrypt → 申请

```
✅ 强制HTTPS
✅ HSTS
```

---

### 5️⃣ 部署后端（8分钟）

```bash
# 终端执行
cd /www/wwwroot/yuzhen-backend

# 安装依赖
composer install --optimize-autoloader --no-dev

# 配置环境
cp .env.example .env
nano .env  # 修改数据库等配置

# 生成密钥
php artisan key:generate
php artisan jwt:secret

# 迁移数据库
php artisan migrate --force
php artisan db:seed --force

# 优化
php artisan config:cache
php artisan route:cache

# 权限
chown -R www:www /www/wwwroot/yuzhen-backend
chmod -R 755 /www/wwwroot/yuzhen-backend
chmod -R 777 storage bootstrap/cache
```

**Nginx配置** - 网站设置 → 配置文件：
```nginx
# Laravel重写规则
location / {
    try_files $uri $uri/ /index.php?$query_string;
}

# CORS
add_header Access-Control-Allow-Origin https://yuzhen-fitness.cn always;
```

---

### 6️⃣ 部署前端（2分钟）

本地构建：
```bash
cd yuzhen_fitness_v2
npm run build
```

上传 `dist/spa/*` 到 `/www/wwwroot/yuzhen-frontend/`

---

### 7️⃣ 定时任务（1分钟）

宝塔 → 计划任务 → Shell脚本 → 每分钟：
```bash
cd /www/wwwroot/yuzhen-backend && php artisan schedule:run >> /dev/null 2>&1
```

## 🆘 快速排错

### API返回502
```bash
systemctl restart php-fpm-82
```

### 目录权限错误
```bash
chown -R www:www /www/wwwroot/yuzhen-backend
chmod -R 777 storage bootstrap/cache
```

### 数据库连接失败
检查 `.env` 中的数据库配置

---

## 📱 重要配置

### .env核心配置
```env
APP_ENV=production
APP_DEBUG=false
APP_URL=https://api.yuzhen-fitness.cn
APP_FRONTEND_URL=https://yuzhen-fitness.cn

DB_HOST=127.0.0.1
DB_DATABASE=数据库名（宝塔自动生成）
DB_USERNAME=用户名（宝塔自动生成）
DB_PASSWORD=密码（宝塔自动生成）

REDIS_HOST=127.0.0.1
REDIS_PORT=6379

CACHE_DRIVER=redis
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis
```
